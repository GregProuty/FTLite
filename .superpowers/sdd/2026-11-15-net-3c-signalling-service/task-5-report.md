## Delivered behavior and API handoff

`POST /v2/rooms/{roomId}/turn` uses the existing Worker route, platform-IP HMAC, Directory lookup and Bearer authentication boundaries. Body keys are exactly `{connectionId,seatGeneration,hostGeneration}`; identity derives from the reserved token. The Room's internal `RoomTurn.issueTurn(currentSeatConnection): Promise<TurnCredentials>` returns the shared `{iceServers,expiresAtEpochMs}` contract. The current-connection stamp is internal, never caller-supplied HTTP authority.

Authorization requires current SQL seat/socket identity and an actual OPEN hibernatable transport. Regular lobby RTC is allowed. A prepared/committed activation blocks lobby issuance; a proposal alone does not. Active issuance additionally requires an acknowledged exact epoch/host generation and a current OPEN host socket with valid host lease. Guests retain their own socket authority and need not be the host. Lost/ended/expired rooms cannot issue. Checks run before admission, after Directory admission, after the provider operation, and after the issuance promise before constructing the success response. Store expiry fences stale authority synchronously.

`room_turn` stores at most four logical-seat timestamps. A generation change, token rejoin, failed provider operation or hibernation does not reset the one-attempt-per-minute cooldown. It is removed when the Room's retained data is deleted. Directory `reserveTurn({roomId,seatId,seatGeneration,connectionId})` remains a `Promise<DomainResult<void>>` RPC. It verifies a committed charged mapping and atomically reserves one of 1,000 attempts per UTC day. It never calls Room and never refunds unknown outcomes. Admission/storage/accounting refusal prevents provider access. `directory_turn` keeps current/previous UTC day counters; reconciliation and its derived alarm remove older rows. There is no stored credential, provider response, retry payload or issuance queue.

Server-only optional `Env.TURN_KEY_ID` and `TURN_KEY_API_TOKEN` select the fixed Cloudflare endpoint. The key must be 32 hex digits and the token bounded printable ASCII. Missing/malformed configuration fails closed. No injectable provider URL or fetch implementation exists in shipping code. Provider failures use fixed retryable `turn-unavailable`/503 and private responses use `no-store`.

The provider operation POSTs `{ttl:3600}`, accepts only an unredirected 201, has one five-second timer/AbortController covering headers and response bytes, and passes only the remaining deadline to the existing bounded reader. Bytes are capped at 16,384 including streamed responses without Content-Length. JSON rejects malformed/duplicate keys; ICE entries are capped at eight, total URLs sixteen, URL UTF-8 bytes 2,048 and credential UTF-8 bytes 512. Strict ICE grammar permits provider STUN/TURN hosts and allowed protocols, rejects alternate destinations/userinfo/path/fragment/encoded hosts, removes port 53, and requires usable TURN with nonempty username/password. Expiry is conservatively Room request-start plus 3,600 seconds. Provider errors/bodies, long-term keys, ephemeral ICE and signals are never persisted or logged.
