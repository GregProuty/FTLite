1. **P1 — All image/font URLs resolve incorrectly** ([line 1097](docs/superpowers/plans/2026-11-10-art-pass.md:1097)). Resolving `./assets/` against `…/assets/manifest.json` produces `…/assets/assets/`. Required assets fail in both dev and packaged builds. **Fix:** use `new URL('.', new URL(manifestUrl, document.baseURI))`.

2. **P1 — Packaged PNG loading still defaults to unsupported file fetching** ([lines 1071–1074](docs/superpowers/plans/2026-11-10-art-pass.md:1071), [1140](docs/superpowers/plans/2026-11-10-art-pass.md:1140)). Installed Pixi defaults to ImageBitmap loading through `fetch`; the manifest’s XHR fallback does not cover PNGs. The proposed fallback assignment also encounters optional `loadTextures.config` under strict typings. **Fix:** configure the image-element path before loading assets under `file:`, guard/assert `config`, and verify the installed build.

3. **P2 — Credits scrolling test fails** ([lines 2266–2270](docs/superpowers/plans/2026-11-10-art-pass.md:2266), [2355–2359](docs/superpowers/plans/2026-11-10-art-pass.md:2355)). The immediate step retains the first frame’s 50 ms, so scroll becomes 2 on the third frame; line 2269 expects 1. **Fix:** perform the immediate step separately, reset elapsed hold time to zero, and accumulate subsequent frames.

4. **P2 — Join-after-credits test disconnects the player it asserts is active** ([lines 2295–2296](docs/superpowers/plans/2026-11-10-art-pass.md:2295)). `release()` supplies only device `a`; the next frame marks newly joined `b` as `reconnect`. **Fix:** release with neutral samples for both devices, or assert before removing `b`.

5. **P2 — Pure HUD extraction happens too late** ([line 37](docs/superpowers/plans/2026-11-10-art-pass.md:37), [2062–2066](docs/superpowers/plans/2026-11-10-art-pass.md:2062)). Through Task 9, HUD tests directly import Pixi through `hud.ts`, and session tests import it transitively through `session.ts`, violating the global constraint. **Fix:** move the model extraction and test/session import changes into Task 1.

6. **P2 — Optional unbound names can crash rendering** ([lines 1111–1117](docs/superpowers/plans/2026-11-10-art-pass.md:1111), [1624–1625](docs/superpowers/plans/2026-11-10-art-pass.md:1624)). Optional names may legally be unbound, but `missing` includes only bindings from failed files. `featureReady` then reports absent features as ready, leading to throwing texture/animation lookups. **Fix:** include unloaded/unbound optional names in `missing`, or determine readiness using `assets.has`.

7. **P2 — Crew movement uses stale tick deltas** ([lines 1683–1686](docs/superpowers/plans/2026-11-10-art-pass.md:1683), [1713–1720](docs/superpowers/plans/2026-11-10-art-pass.md:1713)). Movement/facing uses current sim position minus the previous tick position, rather than successive interpolated positions. Pausing after movement leaves that delta nonzero indefinitely, so stationary crew keep walking. **Fix:** track previous rendered positions separately, derive movement from interpolated deltas, and clear that history on reset.
