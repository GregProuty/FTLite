# Roadmap: the next ten features

Written 2026-11-10 when the owner asked for an autonomous run through the feature list ("take the recommendation and move on"). Each feature goes through the same loop: brainstorm (decisions taken on the recommended option and recorded in the spec), spec, Codex spec review, plan, Codex plan review, subagent-driven execution with per-task reviews, Opus final review, fast-forward merge, Codex implementation review. The foundation spec's build order (`docs/superpowers/specs/2026-11-09-foundation-design.md` §11) covers the first four; the sub-projects in §1 and the open items in §14 give the rest, decomposed so each is playable on its own.

## Someday maybe

Ideas kept for later, not planned. The user, 2026-11-13: "i dont want to complicate things yet".

- **Species (MoO2 lesson: abilities that change how you play):** each player picks a species in the lobby with one ability and one drawback, original archetypes: Stoneborn (need no oxygen; slow, the Medbay can't heal them), Choir (sense boarders and hidden ships through walls, see the enemy's target 3 s early; frail), Splice (fast repairs, heal at consoles; ion stuns them), Kinfolk (double teamwork bonus; weak alone), Ironback (big health, carry two torpedoes; slow in thin air); later the enemy crews too (source: user 2026-11-13, MoO2 transcript)
- **Pick one of three upgrades (MoO2 lesson: forced research specialisation):** each Engineering upgrade tier offers three branches and you buy one (e.g. Weapons 2: rapid recharge, volley link or shield piercing); wrecks, events and captures can hand you a skipped branch (source: user 2026-11-13, MoO2 transcript)
- **Refit and weapon batteries (MoO2 lesson: elegant ship design):** at shops the crew fits weapons and systems into the ship's slots and power budget (two buckets, one budget); the gunner groups weapons into batteries and sets their firing order (strip shields first, then the ion or torpedo into a system) (source: user 2026-11-13, MoO2 transcript)
- **Capture by boarding (MoO2 lesson: disable, board, capture):** disable an enemy's engines and piloting, send an away team across, take the ship for its weapon and scrap; the defenders may self-destruct (source: user 2026-11-13, MoO2 transcript; gap audit P2)

Deferred beyond this list: networking (sub-project 5), a solo drone, the shared luck resource, procedural ships.
