# Upgrades from the Engineering Console (Loop-ii) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spend scrap on system levels and reactor bars from an Upgrades page on the Engineering console, with rising prices; shops stop selling upgrades.

**Architecture:** `run.upgrades` holds levels (0–3), `run.reactorBonus` prices reactor bars, `state.power.capacity` grows; `stations.page` switches the Engineering card between power and upgrades. SIM_VERSION 25.

**Tech Stack:** TypeScript, vitest (node).
