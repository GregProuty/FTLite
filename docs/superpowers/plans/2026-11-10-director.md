# Director (Increment 4-i) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the timer spawner with the director: a stress value and a four-phase pacing machine gate spawns, elapsed-time escalation sets rate, cap, budget and weights, hazard selection down-weights the last type and (at 3 or 4 players) routes toward idle consoles, per `docs/superpowers/specs/2026-11-10-director-design.md`.

**Architecture:** `state.director` replaces `state.spawner`; `sim/director.ts` owns stress, phases, escalation helpers, weights, spawning and `directorSystem` (called where `spawner` was); `xpSystem` maintains `sinceProductive` at the observation point; the HUD gets a phase/stress line. `hazards/spawner.ts` and `tests/spawner.test.ts` are deleted and replaced by `director.ts` and `tests/director.test.ts`.

**Tech Stack:** TypeScript ~5.8, vitest 3 (node), Pixi 8.19 (render task only). No new dependencies.

## Spec amendments made by this plan (recorded in Task 4)

- Build Up re-arming never pulls an already-later timer earlier: `nextSpawnTick = max(nextSpawnTick, tick + round(interval × TICK_HZ × jitter))`. In play the old timer is always earlier (a full cycle lasts at least 70 s and an interval at most 36 s), so behaviour is unchanged; it lets tests silence the director with `director.nextSpawnTick = 1e9` across phase cycles, the idiom dozens of existing tests already use on the spawner.
- `chooseType(weights, u)` takes the unit roll `u` in [0, 1) and scales by the weight sum itself (the old `pickSpawnType(roll)` took a pre-scaled roll).

## Global Constraints

- `tests/boundary.test.ts` stays green: `sim/` imports nothing from render/, input/, app/, pixi, electron; no `Math.random`, `Date`, `performance.now`, `Math.pow`; ASCII only in comments; `window` is banned in sim files.
- Every test runs under node; no test imports pixi; `hudModel.ts` stays pixi-free.
- Determinism: every director timing and type draw comes from `rng.director`, every target draw from `rng.hazards`, in the order the spec fixes (attempt: jitter then type roll; Build Up entry: one jitter draw; stress: no draw). New state (`director` block: `phase, phaseTick, stress, nextStressTick, nextSpawnTick, budgetLeft, lastSpawnTick, lastType`, then `sinceProductive[7]`) is flattened in a `director` section replacing `spawner`, snapshotted and hashed. `SIM_VERSION = 8`; version-7 snapshots rejected.
- Tuning (exact): `STRESS_PERIOD 5`; `STRESS_WEIGHTS { fire 0.25, breach 0.30, power 0.20, debris 0.20, downed 0.40 }`; `STRESS_RISE 0.5`, `STRESS_FALL 0.15` (halved while unattended); `PEAK_LEVEL 0.7`, `RELAX_LEVEL 0.25`; `SUSTAIN_SECONDS 10`, `FADE_TIMEOUT 30`, `RELAX_MIN 30`, `RELAX_MAX 60`, `STALL_SECONDS 60`; `SPAWN_FIRST 15`, `SPAWN_INTERVAL 30`, `SPAWN_JITTER 0.2`, `SPAWN_CAP 3` (kept); `SPAWN_INTERVAL_MIN 10`, `ESCALATION_RATE 0.1`, `SOLO_INTERVAL_MULT 1.5`; `SPAWN_CAP_MAX 6`, `CAP_MINUTES 4`; `BUDGET_BASE 3`, `BUDGET_GROWTH 0.5`; `WEIGHT_MINUTES 4`; `ROUTE_BONUS 2`, `ROUTE_IDLE_SECONDS 60`; `SINCE_CAP 36000`.
- Formulas: `minutes = tick / 3600`; `spawnInterval(m, p) = max(10, 30 / (1 + 0.1 m)) × (p === 1 ? 1.5 : 1)`; `spawnCap(m, p) = max(1, min(6, 3 + floor(m / 4) + floor(max(0, p − 2) / 2)) − (p === 1 ? 1 : 0))`; `cycleBudget(m, p) = max(1, floor((3 + 0.5 m) × max(0.5, p / 2)))`; base weights `[4, 2, 2, 4]` (fire, breach, power, debris) `+ 2 × floor(m / 4)` on power and debris; the `lastType` entry is halved (integer division, minimum 1); then at p ≥ 3 every routed type gets `+ 2 × ROUTE_BONUS`.
- Routing idle per type: fire `idle(Doors)`; breach `min(idle(Doors), idle(LifeSupport))`; power `idle(Engineering)`; debris `min(idle(Science), idle(Weapons), idle(Navigation))`; `idle(kind) = sinceProductive[kind] / TICK_HZ`, 0 for a console not on the ship; the maximum wins if `> ROUTE_IDLE_SECONDS`, and every type tied at the maximum gets the bonus.
- Unattended (one definition): a burning room with no Conscious crew member whose centre is in it; an active breach or failed station with no Conscious crew member within `REACH` of its tile; a Downed crew member with no Conscious crew member within `REACH` centre to centre; in-flight debris is never unattended.
- Per-tick order in `directorSystem`: stress update if due → `phaseStep` (at most one transition) → if Build Up and due, `attemptSpawn` (re-arm first, cap check, type roll, target) → if it succeeded and the budget hit 0, enter Sustain Peak.
- `sinceProductive` is updated in `xpSystem` for every station kind on the ship: 0 when online with a Conscious seated operator and `isProductive`, else `min(SINCE_CAP, v + 1)`.
- Commit messages: imperative, prefixed `feat:`, `test:`, `chore:` or `docs:`; the agent's attribution line as the session requires. `npm run typecheck`, `npm test` and `npm run build` pass at the end of every task.

Add to `tests/helpers/sim.ts`:

```ts
import { Phase } from '../../src/renderer/src/sim/director';

/** Silence the director: no spawn attempt can come due (re-arming never pulls a later timer earlier). */
export function quiet(state: SimState): void { state.director.nextSpawnTick = 1e9; }

/** Put the director in Build Up with a due attempt, plenty of budget and no stress or stall pressure, so one spawn can be observed in isolation. */
export function armSpawn(state: SimState): void {
  const d = state.director;
  d.phase = Phase.BuildUp; d.phaseTick = state.tick; d.lastSpawnTick = state.tick; d.budgetLeft = 99; d.stress = 0; d.nextStressTick = 1e9; d.nextSpawnTick = state.tick;
}
```

```ts
describe('phase machine', () => {
  const at = (s: ReturnType<typeof makeState>, phase: number, phaseTick: number, stress: number, budget = 2) => {
    const d = s.director; d.phase = phase; d.phaseTick = phaseTick; d.stress = stress; d.budgetLeft = budget; d.lastSpawnTick = phaseTick; d.nextStressTick = 1e9; d.nextSpawnTick = 1e9;
  };
  it('Build Up -> Sustain Peak on stress >= 0.7', () => {
    const s = makeState(2); at(s, Phase.BuildUp, 0, PEAK_LEVEL - 0.01); s.tick = 100;
    phaseStep(s); expect(s.director.phase).toBe(Phase.BuildUp);
    s.director.stress = PEAK_LEVEL; phaseStep(s); expect(s.director.phase).toBe(Phase.SustainPeak); expect(s.director.phaseTick).toBe(100);
  });
  it('Build Up -> Sustain Peak on the stall timer, from the last spawn or the phase start, including the initial -1', () => {
    const s = makeState(2); at(s, Phase.BuildUp, 1000, 0.3); s.director.lastSpawnTick = 2000;
    s.tick = 2000 + STALL_SECONDS * T - 1; phaseStep(s); expect(s.director.phase).toBe(Phase.BuildUp);
    s.tick = 2000 + STALL_SECONDS * T; phaseStep(s); expect(s.director.phase).toBe(Phase.SustainPeak);
    const t = makeState(2); at(t, Phase.BuildUp, 500, 0.3); t.director.lastSpawnTick = -1;
    t.tick = 500 + STALL_SECONDS * T - 1; phaseStep(t); expect(t.director.phase).toBe(Phase.BuildUp);
    t.tick = 500 + STALL_SECONDS * T; phaseStep(t); expect(t.director.phase).toBe(Phase.SustainPeak);
  });
  it('Build Up -> Sustain Peak when a real due spawn exhausts the budget, on that tick', () => {
    const s = makeState(0); armSpawn(s); s.director.budgetLeft = 1;
    directorSystem(s);
    expect(activeHazardCount(s)).toBe(1); expect(s.director.budgetLeft).toBe(0); expect(s.director.phase).toBe(Phase.SustainPeak); expect(s.director.lastSpawnTick).toBe(s.tick);
  });
  it('Sustain Peak -> Peak Fade at exactly 10 s', () => {
    const s = makeState(2); at(s, Phase.SustainPeak, 300, 0.9);
    s.tick = 300 + SUSTAIN_SECONDS * T - 1; phaseStep(s); expect(s.director.phase).toBe(Phase.SustainPeak);
    s.tick = 300 + SUSTAIN_SECONDS * T; phaseStep(s); expect(s.director.phase).toBe(Phase.PeakFade);
  });
  it('Peak Fade -> Relax on stress <= 0.25, or at the 30 s timeout with stress high', () => {
    const s = makeState(2); at(s, Phase.PeakFade, 300, RELAX_LEVEL + 0.01); s.tick = 400;
    phaseStep(s); expect(s.director.phase).toBe(Phase.PeakFade);
    s.director.stress = RELAX_LEVEL; phaseStep(s); expect(s.director.phase).toBe(Phase.Relax);
    const t = makeState(2); at(t, Phase.PeakFade, 300, 0.9);
    t.tick = 300 + FADE_TIMEOUT * T - 1; phaseStep(t); expect(t.director.phase).toBe(Phase.PeakFade);
    t.tick = 300 + FADE_TIMEOUT * T; phaseStep(t); expect(t.director.phase).toBe(Phase.Relax);
  });
  it('Relax -> Build Up after 30 s with low stress, not before; at 60 s regardless; re-entry re-arms budget and timer with one draw', () => {
    const s = makeState(2); at(s, Phase.Relax, 600, 0);
    s.tick = 600 + RELAX_MIN * T - 1; phaseStep(s); expect(s.director.phase).toBe(Phase.Relax);
    s.tick = 600 + RELAX_MIN * T; s.director.nextSpawnTick = 0;
    const one = createRng(s.rng.director.s); nextFloat(one);
    phaseStep(s);
    expect(s.director.phase).toBe(Phase.BuildUp); expect(s.director.phaseTick).toBe(s.tick); expect(s.director.budgetLeft).toBe(cycleBudget(s.tick / 3600, 2));
    expect(s.rng.director.s).toBe(one.s);
    expect(s.director.nextSpawnTick).toBeGreaterThanOrEqual(s.tick + Math.round(SPAWN_INTERVAL * T * (1 - SPAWN_JITTER)) - 1);
    expect(s.director.nextSpawnTick).toBeLessThanOrEqual(s.tick + Math.round(SPAWN_INTERVAL * T * (1 + SPAWN_JITTER)) + 1);
    const t = makeState(2); at(t, Phase.Relax, 600, 0.5);
    t.tick = 600 + RELAX_MIN * T; phaseStep(t); expect(t.director.phase).toBe(Phase.Relax);                 // stress too high
    t.tick = 600 + RELAX_MAX * T - 1; phaseStep(t); expect(t.director.phase).toBe(Phase.Relax);
    t.director.stress = 0.9; t.tick = 600 + RELAX_MAX * T; phaseStep(t); expect(t.director.phase).toBe(Phase.BuildUp);   // hard maximum
    const u = makeState(2); at(u, Phase.Relax, 600, 0); u.director.nextSpawnTick = 1e9; u.tick = 600 + RELAX_MIN * T; phaseStep(u);
    expect(u.director.nextSpawnTick).toBe(1e9);                                                            // re-arming never pulls a later timer earlier
  });
  it('no spawn outside Build Up even with a due timer; a peak reached on a due-spawn tick spawns nothing and draws nothing; one transition per tick', () => {
    for (const phase of [Phase.SustainPeak, Phase.PeakFade, Phase.Relax]) {
      const s = makeState(0); at(s, phase, s.tick, 0.5, 5); s.director.nextSpawnTick = s.tick;
      const r = s.rng.director.s; directorSystem(s);
      expect(activeHazardCount(s)).toBe(0); expect(s.rng.director.s).toBe(r);
    }
    const p = makeState(0); armSpawn(p); p.director.stress = PEAK_LEVEL; const r = p.rng.director.s;
    directorSystem(p);
    expect(p.director.phase).toBe(Phase.SustainPeak); expect(activeHazardCount(p)).toBe(0); expect(p.rng.director.s).toBe(r);
    const q = makeState(2); at(q, Phase.SustainPeak, 0, 0); q.tick = 100 * T;                          // long past both the sustain and fade windows
    phaseStep(q); expect(q.director.phase).toBe(Phase.PeakFade);                                        // only one step per call
  });
});

describe('spawning', () => {
  it('the first attempt comes at SPAWN_FIRST and counts fires, breaches, failed stations and debris', () => {
    const s = makeState(2);
    run(s, seconds(SPAWN_FIRST) - 1); expect(activeHazardCount(s)).toBe(0);
    run(s, 2); expect(activeHazardCount(s)).toBe(1);

  it('a blocked attempt (cap full) re-arms the timer with exactly one director draw and no type roll', () => {
    const s = makeState(0); armSpawn(s);

    const one = createRng(s.rng.director.s); nextFloat(one);

    expect(activeHazardCount(s)).toBe(SPAWN_CAP); expect(s.rng.director.s).toBe(one.s);
    expect(s.director.nextSpawnTick).toBeGreaterThanOrEqual(s.tick + Math.round(SPAWN_INTERVAL * T * (1 - SPAWN_JITTER)));
```

```ts
import type { SimState } from './state';
import { nextFloat, nextInt } from '../../../shared/rng';
import { Position, Life, LifeState } from './components';
import { roomAt } from './grid';
import { inReachOfTile } from './interact';
import { StationKind, STATION_COUNT } from './stationKinds';
import { igniteRoom, burningRoomCount } from './hazards/fire';
import { activateBreach, activeBreachCount, freeSites } from './hazards/breach';
import { failStation } from './power';
import { failedStationCount } from './stations';
import { activeDebrisCount, spawnDebris } from './debris';
import { TICK_HZ, REACH, SPAWN_INTERVAL, SPAWN_JITTER, SPAWN_CAP, SPAWN_WEIGHTS, STRESS_PERIOD, STRESS_WEIGHTS, STRESS_RISE, STRESS_FALL, PEAK_LEVEL, RELAX_LEVEL, SUSTAIN_SECONDS, FADE_TIMEOUT, RELAX_MIN, RELAX_MAX, STALL_SECONDS, SPAWN_INTERVAL_MIN, ESCALATION_RATE, SOLO_INTERVAL_MULT, SPAWN_CAP_MAX, CAP_MINUTES, BUDGET_BASE, BUDGET_GROWTH, WEIGHT_MINUTES, ROUTE_BONUS, ROUTE_IDLE_SECONDS } from './tuning';

export const Phase = { BuildUp: 0, SustainPeak: 1, PeakFade: 2, Relax: 3 } as const;
export const PHASE_NAMES = ['Build Up', 'Sustain Peak', 'Peak Fade', 'Relax'] as const;
export const HazardType = { Fire: 0, Breach: 1, Power: 2, Debris: 3 } as const;
const TYPE_COUNT = 4;

export function activeHazardCount(state: SimState): number {
  return burningRoomCount(state) + activeBreachCount(state) + failedStationCount(state) + activeDebrisCount(state);
}

export function minutesOf(state: SimState): number { return state.tick / (60 * TICK_HZ); }

/** Escalation (spec 4-i section 7): the interval shrinks toward a floor; solo crews get more time. */
export function spawnInterval(minutes: number, players: number): number {
  const base = Math.max(SPAWN_INTERVAL_MIN, SPAWN_INTERVAL / (1 + ESCALATION_RATE * minutes));
  return base * (players === 1 ? SOLO_INTERVAL_MULT : 1);
}

export function spawnCap(minutes: number, players: number): number {
  const cap = Math.min(SPAWN_CAP_MAX, SPAWN_CAP + Math.floor(minutes / CAP_MINUTES) + Math.floor(Math.max(0, players - 2) / 2));
  return Math.max(1, cap - (players === 1 ? 1 : 0));
}

export function cycleBudget(minutes: number, players: number): number {
  return Math.max(1, Math.floor((BUDGET_BASE + BUDGET_GROWTH * minutes) * Math.max(0.5, players / 2)));
}

function downedCount(state: SimState): number {
  let n = 0; for (let pid = 0; pid < state.playerCount; pid++) if (Life.state[state.crew[pid]!] === LifeState.Downed) n++; return n;
}

/** Unsmoothed stress: a weighted count of what is wrong right now, clamped to 1 (spec 4-i section 5). */
export function rawStress(state: SimState): number {
  const w = STRESS_WEIGHTS;
  const raw = w.fire * burningRoomCount(state) + w.breach * activeBreachCount(state) + w.power * failedStationCount(state) + w.debris * activeDebrisCount(state) + w.downed * downedCount(state);
  return Math.max(0, Math.min(1, raw));
}

function consciousNear(state: SimState, x: number, y: number): boolean {
  for (let pid = 0; pid < state.playerCount; pid++) {
    const eid = state.crew[pid]!;
    if (Life.state[eid] !== LifeState.Conscious) continue;
    const dx = Position.x[eid]! - x, dy = Position.y[eid]! - y;
    if (Math.sqrt(dx * dx + dy * dy) <= REACH) return true;
  }
  return false;
}

function consciousInRoom(state: SimState, room: number): boolean {
  for (let pid = 0; pid < state.playerCount; pid++) {
    const eid = state.crew[pid]!;
    if (Life.state[eid] === LifeState.Conscious && roomAt(state, Position.x[eid]!, Position.y[eid]!) === room) return true;
  }
  return false;
}

function consciousInReachOfTile(state: SimState, tile: number): boolean {
  for (let pid = 0; pid < state.playerCount; pid++) {
    const eid = state.crew[pid]!;
    if (Life.state[eid] === LifeState.Conscious && inReachOfTile(state, eid, tile)) return true;
  }
  return false;
}

/** The one unattended definition (spec 4-i section 5): fires by room, breaches and failures by reach of the tile, Downed crew by reach; debris never. */
export function anyUnattended(state: SimState): boolean {
  const d = state.derived;
  for (let r = 0; r < state.rooms.fire.length; r++) if (state.rooms.fire[r]! > 0 && !consciousInRoom(state, r)) return true;
  for (let s = 0; s < state.breaches.active.length; s++) if (state.breaches.active[s] && !consciousInReachOfTile(state, d.siteTile[s]!)) return true;
  for (let i = 0; i < state.stations.failed.length; i++) if (state.stations.failed[i] && !consciousInReachOfTile(state, d.stationTile[i]!)) return true;
  for (let pid = 0; pid < state.playerCount; pid++) {
    const eid = state.crew[pid]!;
    if (Life.state[eid] === LifeState.Downed && !consciousNear(state, Position.x[eid]!, Position.y[eid]!)) return true;
  }
  return false;
}

/** One smoothing step: fast up, slow down, slower still while something is unattended. */
export function updateStress(state: SimState): void {
  const d = state.director, raw = rawStress(state);
  const k = raw > d.stress ? STRESS_RISE : (anyUnattended(state) ? STRESS_FALL * 0.5 : STRESS_FALL);
  d.stress = Math.max(0, Math.min(1, d.stress + (raw - d.stress) * k));
}

function idleOf(state: SimState, kind: number): number {
  return state.derived.stationOfKind[kind]! < 0 ? 0 : state.director.sinceProductive[kind]! / TICK_HZ;
}

/** Responding-console idle time per hazard type (spec 4-i section 7); -1 for every type when routing is disabled (fewer than 3 players). */
export function routeIdle(state: SimState): number[] {
  if (state.playerCount < 3) return [-1, -1, -1, -1];
  const doors = idleOf(state, StationKind.Doors), ls = idleOf(state, StationKind.LifeSupport), eng = idleOf(state, StationKind.Engineering);
  const handoff = Math.min(idleOf(state, StationKind.Science), idleOf(state, StationKind.Weapons), idleOf(state, StationKind.Navigation));
  return [doors, Math.min(doors, ls), eng, handoff];
}

/** Doubled base weights, escalation on the demanding types, the last type halved, then the routing bonus on every type tied for the longest idle. */
export function typeWeights(state: SimState): number[] {
  const m = minutesOf(state), grow = 2 * Math.floor(m / WEIGHT_MINUTES);
  const w = [2 * SPAWN_WEIGHTS.fire, 2 * SPAWN_WEIGHTS.breach, 2 * SPAWN_WEIGHTS.power + grow, 2 * SPAWN_WEIGHTS.debris + grow];
  const last = state.director.lastType;
  if (last >= 0) w[last] = Math.max(1, Math.floor(w[last]! / 2));
  const idle = routeIdle(state), top = Math.max(...idle);
  if (top > ROUTE_IDLE_SECONDS) for (let t = 0; t < TYPE_COUNT; t++) if (idle[t] === top) w[t]! += 2 * ROUTE_BONUS;
  return w;
}

/** Map a unit roll onto the weight intervals in type order. */
export function chooseType(weights: readonly number[], u: number): number {
  let total = 0; for (const w of weights) total += w;
  const x = u * total;
  let acc = 0;
  for (let t = 0; t < weights.length; t++) { acc += weights[t]!; if (x < acc) return t; }
  return weights.length - 1;
}

function spawnOfType(state: SimState, type: number): boolean {
  if (type === HazardType.Fire) {
    const candidates: number[] = [];
    for (let r = 0; r < state.rooms.fire.length; r++) if (state.rooms.fire[r] === 0) candidates.push(r);
    if (!candidates.length) return false;
    return igniteRoom(state, candidates[nextInt(state.rng.hazards, candidates.length)]!);
  }
  if (type === HazardType.Breach) {
    const sites = freeSites(state);
    if (!sites.length) return false;
    return activateBreach(state, sites[nextInt(state.rng.hazards, sites.length)]!);
  }
  if (type === HazardType.Power) {
    const candidates: number[] = [];
    for (let i = 0; i < state.stations.failed.length; i++) if (!state.stations.failed[i]) candidates.push(i);
    if (!candidates.length) return false;
    failStation(state, candidates[nextInt(state.rng.hazards, candidates.length)]!); return true;
  }
  return spawnDebris(state) >= 0;
}

function rearm(state: SimState): void {
  const d = state.director, u = nextFloat(state.rng.director);
  const jitter = 1 + SPAWN_JITTER * (2 * u - 1);
  d.nextSpawnTick = Math.max(d.nextSpawnTick, state.tick + Math.round(spawnInterval(minutesOf(state), state.playerCount) * TICK_HZ * jitter));   // never pulls a later timer earlier
}

/** A due Build Up attempt: re-arm first, then the cap, then one type roll and the target draw. Returns whether a hazard was spawned. */
export function attemptSpawn(state: SimState): boolean {
  const d = state.director;
  d.nextSpawnTick = state.tick;                                                   // the re-arm below is relative to now
  rearm(state);
  if (activeHazardCount(state) >= spawnCap(minutesOf(state), state.playerCount)) return false;
  const type = chooseType(typeWeights(state), nextFloat(state.rng.director));
  if (!spawnOfType(state, type)) return false;
  d.lastSpawnTick = state.tick; d.lastType = type; d.budgetLeft -= 1;
  return true;
}

export function enterPhase(state: SimState, phase: number): void {
  const d = state.director;
  d.phase = phase; d.phaseTick = state.tick;
  if (phase === Phase.BuildUp) { d.budgetLeft = cycleBudget(minutesOf(state), state.playerCount); rearm(state); }
}

/** Exit conditions of the current phase; at most one transition (spec 4-i section 6). */
export function phaseStep(state: SimState): void {
  const d = state.director, tick = state.tick, elapsed = (tick - d.phaseTick) / TICK_HZ;
  switch (d.phase) {
    case Phase.BuildUp:
      if (d.stress >= PEAK_LEVEL || d.budgetLeft <= 0 || tick - Math.max(d.lastSpawnTick, d.phaseTick) >= STALL_SECONDS * TICK_HZ) enterPhase(state, Phase.SustainPeak);
      break;
    case Phase.SustainPeak:
      if (elapsed >= SUSTAIN_SECONDS) enterPhase(state, Phase.PeakFade);
      break;
    case Phase.PeakFade:
      if (d.stress <= RELAX_LEVEL || elapsed >= FADE_TIMEOUT) enterPhase(state, Phase.Relax);
      break;
    default:
      if ((elapsed >= RELAX_MIN && d.stress <= RELAX_LEVEL) || elapsed >= RELAX_MAX) enterPhase(state, Phase.BuildUp);
  }
}

/** Step 5: stress if due, phase exits, then a Build Up spawn attempt; a spawn that spends the last budget ends the Build Up at once. */
export function directorSystem(state: SimState): void {
  const d = state.director;
  if (state.tick >= d.nextStressTick) { updateStress(state); d.nextStressTick += STRESS_PERIOD * TICK_HZ; }
  phaseStep(state);
  if (d.phase === Phase.BuildUp && state.tick >= d.nextSpawnTick) {
    const spawned = attemptSpawn(state);
    if (spawned && d.budgetLeft <= 0) enterPhase(state, Phase.SustainPeak);
  }
}
```
