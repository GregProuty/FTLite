# Working Together (Coop-i) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Science locks the enemy's rotating shield frequency for Weapons; two crew on one target work faster; a callout button; teamwork shown at the end of a run.

**Architecture:** Sim: two enemy fields (rotation and lock), a team multiplier in `interact.ts` progress, shared revive, two telemetry counters (SIM_VERSION 22). Callouts live outside the sim: input source → app state → a render layer, never in `Intent`.

**Tech Stack:** TypeScript, Pixi 8.19, vitest (node).

- Spec: `docs/superpowers/specs/2026-11-12-coop-i-design.md`; its section 8 Amendments (C1–C5) override sections 1 and 2.
- `SIM_VERSION` 21 → 22; version-21 snapshots rejected; `npm run bless` exactly once, in Task 5.
- Values: `SHIELD_ROTATE 20`, `LOCK_SECONDS 8`, `LOCK_HIT_BONUS 0.15`, `TEAM_MULT 1.25`, callout bubble 3 s.
- Callout keys: `kb:0` gets `KeyR` (beside E, F and Q); `kb:1` gets `Slash` (beside Enter and right Shift); gamepads get the first face or shoulder button the current mapping in `src/renderer/src/input/sources.ts` leaves unused.
