# Sectors, Fuel, the Pursuit and a Peaceful Start (Loop-i) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** FTL's route loop: three sectors of beacons with sideways routes, fuel, a pursuing fleet front, a peaceful first beacon per sector, and beacon contents hidden until you jump there.

**Architecture:** The run's single 8-column map becomes a per-sector 6-column map with stride 4 and sideways edges; new run fields for sector, fuel, pursuit and waiting; `depth` replaces `column` in scaling; the director and enemy clocks start at the first jump. SIM_VERSION 24.

**Tech Stack:** TypeScript, Pixi 8.19, vitest (node).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-11-12-sectors-design.md`, including section 4b (the user's peaceful start and hidden beacons) and the S1–S7 review rules, which override earlier text.
- Values: `SECTORS 3`, `SECTOR_COLUMNS 6`, middle beacons 2–4, `FUEL_START 8`, `FUEL_COST 12` scrap for 2, `WAIT_SECONDS 20`, `WAIT_FUEL_CHANCE 0.6` for 2 fuel, kill fuel 1–2, field fuel 1, `PURSUIT_START −1.5`, `PURSUIT_STEP 0.75`, `PURSUIT_HULL_MULT 1.5`, pursuit fire interval × 0.75; type thresholds Shop 0.15, Event 0.25, Asteroid 0.15, Empty 0.15, Hazard the rest.
- `SIM_VERSION` 23 → 24; `npm run bless` exactly once, in Task 6.
- This feature rewrites the run's shape, so many existing tests that assume the 8-column map, the timed first enemy or `run.column` scaling must be updated. Update each to the new rule, never delete coverage, and list every changed test file with the reason in the spec amendments.
- Gates are re-recorded before (Task 1 step 1) and after (Task 6). The jump and run gates follow the new victory rule. No health floor is lowered; if a gate fails, stop and report with figures.
