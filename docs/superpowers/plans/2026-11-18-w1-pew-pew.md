# W-1 Pew Pew Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the crew Cutter and the enemy Hunter a manual skill-shot gun, the pew pew: aimed with the mouse inside a ±60° cone on the Weapons map, 3 shots in thirds, pooled rounds that strip shields, chip hull and shoot torpedoes out of the air, with Hunter attack and point defence, a PEW card, sound, and streaks on the map.

**Architecture:** A new sim module `sim/tactical/pew.ts` holds the pew's rules (charge, aim clamp in fine heading units, firing from the nose, the swept-segment round step reusing `gun.ts`'s `segmentEntry`, hits). The pew's state lives on each `ShipSystems` record (`pewCharge`, `pewShots`, `pewHits`), in a new 16-entry round pool `TacticalState.pew` (the `GunRound` shape) and two Hunter fields (`pewBurst`, `pewClock`); all of it is hashed, snapshotted and bounded through `sim/tactical/hash.ts`, so the duel snapshot follows with no snapshot code change. A new duel command `pewFire {aim, aimAcc}` is admitted in `sim/duel/step.ts` last in `WEAPON_ORDER` and reaches the sim as `ShipInput.pewAim` (one fine aim per tick, −1 none). The views read the pool and two new events (`pewFire`, `pewHit`).

**Tech Stack:** TypeScript, Vitest (+ jsdom for UI tests), Pixi.js (tactical layer), React + zustand (console), zod (codec), Electron/electron-vite.

## Decisions where the spec leaves room, and where the code forces a choice

1. **Version bump first, gameplay bless last** (see Global Constraints, Version). The caller's "re-recorded once at the end" holds for the gameplay change; the bump itself must be blessed alone first because `blessRefusal` refuses a bump whose duel runs changed.
2. **"In this order" means nearest first, ties in the order.** The round hits whatever its segment enters first (smallest entry parameter `t`); at an equal `t`, rock beats planet beats the other ship's torpedo beats the other ship (checked in that order with strict `<`).
3. **"Armed crew torpedo" for the Hunter's defence is any crew torpedo in flight.** The code's only arming is `MISSILE_ARM_TICKS`, which guards a torpedo's *own* ship; a crew torpedo can hit the Hunter from its first tick.
4. **Pew firing is not gated by Weapons damage** in W-1 (spec §6 decision 4 extends to firing: the pew is the gun that still works). Recharge never changes with damage either.
5. **Both pew ships start a round with a full charge** (as the crew laser starts full), so "3 rapid fires succeed" from the first tick.
6. **A shot-down torpedo's telemetry:** the event cause is `'shot'` (spec), but the round record's `MissileLoss` keys are a stored wire shape (`net/duelRecord.ts`, playtest JSONL files), so telemetry counts a `'shot'` ending under the existing `missile` loss (destroyed by a weapon). The terminal causes gain `'pew'` (appended after `'gun'`, as Valkyrn-i appended `'gun'`; old records still parse).
7. **Hostility:** a crew pew round fired turns the Hunter hostile, cause `'pew'` (laser, gun, pew, missile, clock), as every other crew shot does.
8. **Left click on the Weapons map always fires the pew** (unless a weapon card is picked up, when the click keeps today's meaning). At Weapons the contact window now opens by T and the LASER / TORPEDO cards (1 / 2), not by clicking the enemy marker: a skill shot aimed at the enemy must not open a window instead. Helm and Science keep the map click; the Flight seat keeps its gun. The React cards and the contact window take their own pointer events, so clicking them never reaches the canvas.
9. **The pew sound reuses two of the existing Kenney `laserSmall` files.** No new Kenney laser sample is on disk (`public/assets/raw/kenney-sci-fi-sounds/` holds only `laserSmall_000..004` and `laserLarge_000..004`), and the manifest refuses a file listed twice. So `sfx.pew` takes `laserSmall_003` and `laserSmall_004` (`numbers: [3, 4]`) and the crew laser keeps `laserSmall_000..002` (`numbers: [0, 1, 2]`); the pew plays them faster (`rate 1.5`) and short (`dur 0.18`). A distinct sample (Kenney's `laserRetro_*`) is a later swap of the two numbers' stem.
10. **The PEW card is a row at the top of the Weapons block**, above the LASER and TORPEDO cards (the block grows from 216 to 244 high; its top moves from 492 to 464; every existing element keeps its screen position). Three cards side by side would not fit the existing card text in 300 px.
11. **The scripted gunner fires the pew** (attack with lead on the Hunter, defence against the Hunter's torpedo within 300, at most one round every `SCRIPTED_PEW_GAP` ticks), so the duel gates measure the new primary weapon. The Valkyrn scripted pilot does not (spec §6: no pew on the Valkyrn), but the Hunter's pew fires at the Valkyrn, so Task 6 tunes against both gates.
12. **Interior view:** no rounds are drawn inside the ship; a pew hit on the crew ship is seen only as its effect (the shield and hull readouts) and a 1 px console-map shake. Pew hits never hurt characters or start fires (they never raise a room level, and `health.ts`/`fire.ts` read only laser and torpedo events).

```ts
/** One duel tick with the crew firing the pew straight along its nose, or not. Returns whether a crew round went out. */
function tick(st: TacticalState, fire: boolean): boolean {
  const before = st.systems[0].pewShots;
  stepDuel(st, { ...IDLE_INPUT, pewAim: fire ? st.ships[0].heading * HEADING_COUNT : -1 });
  return st.systems[0].pewShots > before;
}
/** The offset of a tactical field in flattenTactical's values. */
const offsetOf = (s: TacticalState, name: string): number => {
  let at = 0;
  for (const m of TACTICAL_MODULES) for (const f of m.fields(s)) { if (f.name === name) return at; at += f.count; }
  throw new Error(`no tactical field ${name}`);
};
```

```ts
// Pew pew (spec 2026-11-18-pew-pew-weapons-design §1, §4; W-1): the crew Cutter's and the Hunter's skill-shot gun, on a
// class whose pew slot is not null. Its charge is ticks on the systems record: a third of the bar per rechargeTicks, shots
// thirds, a round spending one; it refills every tick, attended or not, whatever the Weapons damage (spec §6 decision 4).
// The aim is a fine heading (AIM_STEPS to the turn: a heading index times HEADING_COUNT plus its fraction), clamped in
// that space into ±arcSteps about the heading at the moment of firing. A round leaves the nose at the round speed along
// the aim, ignoring the ship's velocity, into the shared pool tactical.pew (gun.ts placeRound's pick). firePew runs from
// applyWeaponsInput (before anything moves); stepPew (Task 3) after the gun rounds. Only + − × ÷ and sqrt.
import type { PewDef } from './defs';
import { dirBetween, hx, hy } from './direction';
import { placeRound } from './gun';
import { classOf, type TacticalState } from './state';
import { AIM_STEPS, HEADING_COUNT } from './tuning';

/** A full charge in ticks: every third stored. */
export function pewFull(def: PewDef): number { return def.shots * def.rechargeTicks; }

/** Whether ship i's pew holds at least one full third (a round can fire); never for a class without the pew. */
export function pewReady(state: TacticalState, i: number): boolean {
  const def = classOf(state, i).slots.pew;
  return def !== null && state.systems[i]!.pewCharge >= def.rechargeTicks;
}

/** A pewFire command's aim (spec §4): a heading index 0..255 and its fraction aimAcc 0..255, both integers. */
export function validAim(aim: unknown, aimAcc: unknown): boolean {
  return typeof aim === 'number' && typeof aimAcc === 'number' && Number.isInteger(aim) && Number.isInteger(aimAcc)
    && aim >= 0 && aim < HEADING_COUNT && aimAcc >= 0 && aimAcc < HEADING_COUNT;
}

/** The fine aim `aim` clamped into ±arcSteps about heading index `heading` (spec §1), in fine heading space: the signed
 *  difference d = ((aim − heading·256 + 1.5·AIM_STEPS) mod AIM_STEPS) − AIM_STEPS/2, clamped, added back and wrapped.
 *  Integers in, an integer 0..AIM_STEPS − 1 out. */
export function clampAim(heading: number, aim: number, arcSteps: number): number {
  const base = heading * HEADING_COUNT, d = ((aim - base + AIM_STEPS + AIM_STEPS / 2) % AIM_STEPS) - AIM_STEPS / 2;
  const c = d > arcSteps ? arcSteps : d < -arcSteps ? -arcSteps : d;
  return (base + c + AIM_STEPS) % AIM_STEPS;
}

/** The unit direction of fine aim `aim`, between its two heading table entries. */
export function aimDir(aim: number): [number, number] {
  return dirBetween(Math.floor(aim / HEADING_COUNT), (aim % HEADING_COUNT) / HEADING_COUNT);
}

/** Ship i's muzzle: its centre plus the nose offset along its heading. */
export function pewMuzzle(state: TacticalState, i: number): { x: number; y: number } {
  const s = state.ships[i]!, f = classOf(state, i).slots.pew?.muzzleForward ?? 0;
  return { x: s.x + hx(s.heading) * f, y: s.y + hy(s.heading) * f };
}

/** Fire ship i's pew along fine aim `aim` (spec §1): with the pew, a valid aim (an integer 0..AIM_STEPS − 1) and at least
 *  a third stored, a round leaves the muzzle at the round speed along the clamped aim, a third is spent, the shot is
 *  counted and a pewFire event pushed; returns whether it fired. */
export function firePew(state: TacticalState, i: number, aim: number): boolean {
  const def = classOf(state, i).slots.pew, s = state.systems[i]!;
  if (!def || !Number.isInteger(aim) || aim < 0 || aim >= AIM_STEPS || s.pewCharge < def.rechargeTicks) return false;
  const [ux, uy] = aimDir(clampAim(state.ships[i]!.heading, aim, def.arcSteps)), m = pewMuzzle(state, i);
  placeRound(state, { x: m.x, y: m.y, vx: ux * def.speed, vy: uy * def.speed, age: 0, owner: i }, state.pew);
  s.pewCharge -= def.rechargeTicks; s.pewShots++;
  state.events.push({ kind: 'pewFire', ship: i, x: m.x, y: m.y });
  return true;
}

/** One tick of ship i's pew recharge (spec §1): one tick of charge while below full, every tick. */
export function tickPew(state: TacticalState, i: number): void {
  const def = classOf(state, i).slots.pew, s = state.systems[i]!;
  if (def && s.pewCharge < pewFull(def)) s.pewCharge++;
}
```

```ts

/** Owner's pew round hit ship k at (x, y) (spec §1): with a shield layer up it strips one (the shield clock and the gun's
 *  wear go to 0, as any strip); else it costs the owner's pew hull. Never a room level. The owner counts the hit; a pewHit
 *  event marks it. */
function pewHit(state: TacticalState, owner: number, k: number, x: number, y: number): void {
  const def = classOf(state, owner).slots.pew, t = state.systems[k]!;
  if (!def) return;
  state.systems[owner]!.pewHits++;
  const stripped = t.shields > 0;
  if (stripped) { t.shields--; t.shieldClock = 0; t.gunWear = 0; }
  else t.hull = Math.max(0, t.hull - def.hull);
  state.events.push({ kind: 'pewHit', ship: k, owner, stripped, hull: !stripped, x, y });
}

/**
 * Every pew round in flight, in pool order (spec §1): it flies straight one tick (no gravity, no drag; it also moves on its
 * spawn tick) and ages; its segment from the old to the new position is swept (gun.ts segmentEntry) against the asteroids,
 * the planet, every torpedo in flight that another ship owns (its post-move position) and every other active ship (its
 * post-move circle). The smallest entry wins; on a tie the earlier of rock, planet, torpedo, ship (strict <, in that order).
 * A torpedo is shot down (missiles.ts shootDown), a ship takes pewHit at the entry point, a rock or the planet only stops
 * it. A round that hit anything, or reached its life, ends; an ended entry holds zeros. Never its own ship or torpedo.
 */
export function stepPew(state: TacticalState): void {
  for (const r of state.pew) {
    if (!r.active) continue;
    const ox = r.x, oy = r.y, life = classOf(state, r.owner).slots.pew?.lifeTicks ?? 0;
    r.x += r.vx * DT; r.y += r.vy * DT; r.age++;
    let best = 2, hit: 'none' | 'solid' | 'torpedo' | 'ship' = 'none', k = -1;   // entry parameters are at most 1
    const half = Math.max(Math.abs(r.x - ox), Math.abs(r.y - oy)) / 2;
    for (const a of queryGrid(state.grid, (ox + r.x) / 2, (oy + r.y) / 2, half)) {
      const rock = state.map.asteroids[a]!, t = segmentEntry(ox, oy, r.x, r.y, rock.x, rock.y, rock.r);
      if (t >= 0 && t < best) { best = t; hit = 'solid'; }
    }
    const p = state.map.planet, tp = segmentEntry(ox, oy, r.x, r.y, p.x, p.y, p.r);
    if (tp >= 0 && tp < best) { best = tp; hit = 'solid'; }
    for (const m of state.missiles) {
      if (!m.active || m.owner === r.owner) continue;
      const t = segmentEntry(ox, oy, r.x, r.y, m.x, m.y, classOf(state, m.owner).slots.missile.radius);
      if (t >= 0 && t < best) { best = t; hit = 'torpedo'; k = m.owner; }
    }
    state.ships.forEach((s, j) => {
      if (!s.active || j === r.owner) return;
      const t = segmentEntry(ox, oy, r.x, r.y, s.x, s.y, classOf(state, j).radius);
      if (t >= 0 && t < best) { best = t; hit = 'ship'; k = j; }
    });
    if (hit === 'torpedo') shootDown(state, k);
    else if (hit === 'ship') pewHit(state, r.owner, k, ox + (r.x - ox) * best, oy + (r.y - oy) * best);
    if (hit !== 'none' || r.age >= life) Object.assign(r, emptyRound());
  }
}
```

```ts
/** W-1 (pew pew spec §1): ship i's lead on a target at (tx, ty) moving at (tvx, tvy): the fine aim (a whole heading index ×
 *  HEADING_COUNT) from its muzzle to where a round fired now meets the target holding its velocity. A pew round does not
 *  inherit the ship's velocity, so the target's own velocity is used. −1 without the pew or an intercept. */
export function pewLead(state: TacticalState, i: number, tx: number, ty: number, tvx: number, tvy: number): number {
  const def = classOf(state, i).slots.pew;
  if (!def) return -1;
  const m = pewMuzzle(state, i), rx = tx - m.x, ry = ty - m.y, t = interceptTime(rx, ry, tvx, tvy, def.speed);
  if (t < 0) return -1;
  const h = nearestHeading(rx + tvx * t, ry + tvy * t);
  return h < 0 ? -1 : h * HEADING_COUNT;
```

```ts
/** The Hunter's seeded aim error on a fine aim (spec §1): one draw, uniform in ±HUNTER_PEW_ERROR_STEPS, wrapped. */
function aimError(state: TacticalState, aim: number): number {
  return (aim + nextInt(state.rng, 2 * HUNTER_PEW_ERROR_STEPS + 1) - HUNTER_PEW_ERROR_STEPS + AIM_STEPS) % AIM_STEPS;
}

/**
 * W-1 (pew pew spec §1): the Hunter's pew this tick, a fine aim or −1. The burst clock counts down every call. With less
 * than a third stored there is no shot and the burst ends. Defence first: its target's torpedo in flight within
 * HUNTER_PD_RANGE and inside the cone is tried for once a tick (one roll, 1 in HUNTER_PD_ODDS), led with the round speed
 * and the aim error. Then attack: its target ship within PEW_RANGE and inside the cone, in bursts of the class's shots
 * HUNTER_PEW_GAP ticks apart; a burst starts only on a full charge and ends when the ship leaves the cone or the range.
 * Draws from rng.tactical, in order: the defence roll, then one error for the shot.
 */
function hunterPew(state: TacticalState, i: number): number {
  const def = classOf(state, i).slots.pew, h = state.hunter;
  if (h.pewClock > 0) h.pewClock--;
  if (!def || !pewReady(state, i)) { h.pewBurst = 0; return -1; }
  const me = state.ships[i]!, target = state.systems[i]!.target, crew = state.ships[target]!, torp = missileOf(state, target);
  if (torp) {
    const dx = torp.x - me.x, dy = torp.y - me.y;
    if (dx * dx + dy * dy <= HUNTER_PD_RANGE * HUNTER_PD_RANGE && inArc(me.heading, dx, dy, PEW_ARC_COS) && nextInt(state.rng, HUNTER_PD_ODDS) === 0) {
      const aim = pewLead(state, i, torp.x, torp.y, torp.vx, torp.vy);
      if (aim >= 0) return aimError(state, aim);
    }
  }
  const cx = crew.x - me.x, cy = crew.y - me.y;
  if (!crew.active || cx * cx + cy * cy > PEW_RANGE * PEW_RANGE || !inArc(me.heading, cx, cy, PEW_ARC_COS)) { h.pewBurst = 0; return -1; }
  if (h.pewBurst === 0) {
    if (state.systems[i]!.pewCharge < pewFull(def)) return -1;   // after a burst it waits for every third
    h.pewBurst = def.shots; h.pewClock = 0;
  }
  if (h.pewClock > 0) return -1;
  const aim = pewLead(state, i, crew.x, crew.y, crew.vx, crew.vy);
  if (aim < 0) return -1;
  h.pewBurst--; h.pewClock = HUNTER_PEW_GAP;
  return aimError(state, aim);
}
```
