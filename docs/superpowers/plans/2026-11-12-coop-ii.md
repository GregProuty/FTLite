# Working Together, Part Two (Coop-ii) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A timed evasive manoeuvre that doubles the dodge chance on a teammate's call; torpedoes carried by hand from a magazine; crew votes on events and a two-person jump confirmation.

**Architecture:** Run fields for the manoeuvre and the votes, a crew `carrying` field, an optional ship `magazine` tile (cutter only); a vote step that replaces events' immediate resolution; non-seated Confirm presses routed to votes and confirmations while one is open. SIM_VERSION 23.

**Tech Stack:** TypeScript, vitest (node).
