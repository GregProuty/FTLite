# FTLite Art Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder visuals of Increments 0-1 with open-licence pixel art (Cozy Space Interiors, Puny Characters, Reactorcore fire, Kenney UI and prompts, m5x7 font) plus optional in-house pieces, behind an assets manifest that proves provenance and generates the credits. The simulation, its hashes and goldens do not change.

**Architecture:** A git-tracked `public/` directory (Vite public dir) holds the packs as downloaded and a `manifest.json` that records provenance and, for sheets, the frame grid and named frames and animations. A zod schema validates the manifest; a name contract (`assetNames.ts`) lists every name the renderer uses; a licence allow-list (`licenses.ts`) mirrors spec §12; a script generates `THIRD_PARTY_NOTICES.txt` and `credits.generated.ts` from the manifest. The renderer loads the manifest at startup, slices sheets at load, and draws floors, walls, reconciled door animation, crew `AnimatedSprite`s, hazard sprites and a bitmap-font HUD; every optional (in-house) piece has a Graphics fallback. All decisions are pure, unit-tested functions; Pixi is never run under node.

**Tech Stack:** TypeScript ~5.8, electron-vite 5.0.0 (Vite 7), Electron 37.10.3, pixi.js 8.19.0 (`Assets`, `Texture`, `Rectangle`, `Sprite`, `AnimatedSprite`, `NineSliceSprite`, `BitmapFont`, `BitmapText`), zod ^3.23, vitest 3.2.7, tsx, node:fs.

**Spec:** `docs/superpowers/specs/2026-11-10-art-pass-design.md`. Parent: `docs/superpowers/specs/2026-11-09-foundation-design.md` §7, §12.

## Global Constraints

- No file under `src/renderer/src/sim/` or `src/shared/` changes. `tests/boundary.test.ts` must stay green (sim/ and shared/ import nothing from render/, input/, app/, pixi, electron; no `Math.random`, `Date`, `performance.now`, `Math.sin/cos/atan2/pow/hypot`, `window`, `document`, even in comments).
- Nothing in `src/renderer/src/input/` changes.
- The golden replay (`tests/golden/basic.json`) is not re-blessed; `npm run bless` is not run.
- Every test runs under node (`vitest.config.ts` environment `node`). Pixi is never imported by a test or by any file a test imports. Pure helpers live in files that do not import `pixi.js`.
- Art scale: 16 px native drawn at 2x. `TILE_PX = 32` (from `src/shared/resolution.ts`). Nearest-neighbour scaling on every texture and on the bitmap font.
- Allowed licences (SPDX-style ids, the only values the manifest accepts): `CC0-1.0`, `CC-BY-3.0`, `CC-BY-4.0`, `OGA-BY-3.0`, `OFL-1.1`, `original`, and `CC-BY-SA-4.0` only when `modifications` is `"none"`. Never GPL-only, NC, ND, personal-use, no-licence itch, or Gen-AI material.
- Asset layout: `public/assets/raw/<pack>/...` (third-party), `public/assets/art/{crew,tiles,fx,icons}/...` (in-house), `public/assets/manifest.json`, `public/THIRD_PARTY_NOTICES.txt` (generated), `src/renderer/src/render/credits.generated.ts` (generated). The loader fetches `./assets/manifest.json` relative to `index.html`.
- Manifest entry fields: `file`, `title`, `author`, `source`, `archived`, `license`, `licenseUrl`, `retrieved`, `modifications`, `credit`, `required` (default true), and exactly one of `name` (single image or font) or `sheet` (`frameW`, `frameH`, `frames`, `animations`), plus optional `nineSlice`, `editedBy`, `licenseFile`. Frame indices are row-major over the grid.
- Name contract: every name the renderer uses is listed in `src/renderer/src/render/assetNames.ts` as `required` (must be bound in the manifest) or `optional` (may be unbound). The assets test asserts every required name is bound exactly once, no name is bound twice, every bound name is listed.
- Runtime rule: a `required` manifest file that is missing or fails to load stops startup with a DOM message listing the files; an optional file that is missing or fails to load puts its names in `missing`, logs one `console.warn` naming the file, and the feature uses its Graphics fallback. A manifest that fails validation stops startup with the zod message on the DOM.
- Door animation: `DOOR_ANIM_SECONDS = 0.25`; `advanceDoor(progress, target, dt, DOOR_ANIM_SECONDS)` moves progress towards target by `dt / DOOR_ANIM_SECONDS` and clamps to [0, 1]. Sealed shows `door.sealed` regardless of progress; otherwise `door.open` frame `round(progress × (n − 1))`. Target 1 for Open, 0 for Closed or Sealed. Initial progress on a new run: 1 for Open, else 0.
- Geometry: crew sprite anchor (0.5, 0.75) at the crew member's sim position. A wall tile gets the tall 16×32 front-wall sprite (anchor bottom-left on the wall tile, extending one tile upward) only when the tile above is not a floor (void, wall or out of bounds); otherwise the flat `wall.flat` frame. Wall sprites are added in row order. Crew draw above all tiles (no y-sorting).
- Hazards: breach decal `breach.h` when the site's floor neighbour is above or below it, `breach.v` when left or right; vent direction is the vector from the floor neighbour to the site tile; damaged-floor overlay only on floor tiles (breach: the 4-neighbour floor tiles of the site in the breached room; fire: every tile that displayed a flame), persisted per run in `RenderMemory`; flame count `ceil(fire / FIRE_CAP × tiles)` on a deterministic subset that grows stably; low-oxygen tint threshold `frac < 0.98`.
- Per-player identity is a tint on one light crew body via `sprite.tint` from `CREW_COLORS = [0x4fc3f7, 0x81c784, 0xffb74d, 0xe57373]`; Dead crew are greyscale (tint 0x777777).
- HUD: `HudPlayer.prompt` becomes `interactPrompt` and `confirmPrompt`; `deviceKind: 'kb0' | 'kb1' | 'pad' | null` from the slot key (`kb:0` → `kb0`, `kb:1` → `kb1`, `gp:*` → `pad`, otherwise `null`); glyphs Interact → `prompt.kb.E` / `prompt.kb.Enter` / `prompt.pad.A`; Confirm → `prompt.kb.F` / `prompt.kb.ShiftRight` / `prompt.pad.X`; Cancel → `prompt.kb.Q` / `prompt.kb.Backspace` / `prompt.pad.B` (lobby and game-over banners only).
- Credits sub-state: Cancel from an active slot in the lobby opens it; while open joins are suspended (`allowJoin: false`) and frames of slots that became active this frame are ignored; Confirm or Cancel closes it and Confirm does not start the run; a frame with both pressed closes it and nothing else happens; up/down on an active stick scrolls one line per 150 ms while held.
- `renderer.reset()` clears all per-run render memory; `session.start()` calls it before the first draw of a new run.
- Commit messages: imperative, prefixed `feat:`, `test:`, `chore:`, `spec:` or `docs:`; the agent's attribution line as the session requires.
- `npm run typecheck`, `npm test` and `npm run build` must pass at the end of every task.

```ts
/** The §12 allow-list, SPDX-style. The single place the licence rule lives in code. */
export const LICENSES = ['CC0-1.0', 'CC-BY-3.0', 'CC-BY-4.0', 'OGA-BY-3.0', 'OFL-1.1', 'original', 'CC-BY-SA-4.0'] as const;
export type License = (typeof LICENSES)[number];

/** Author string every piece drawn from scratch carries. Change it here and in the manifest together. */
export const OWNER_AUTHOR = 'FTLite project owner';

export const LICENSE_URLS: Readonly<Record<Exclude<License, 'original'>, string>> = {
  'CC0-1.0': 'https://creativecommons.org/publicdomain/zero/1.0/',
  'CC-BY-3.0': 'https://creativecommons.org/licenses/by/3.0/',
  'CC-BY-4.0': 'https://creativecommons.org/licenses/by/4.0/',
  'OGA-BY-3.0': 'https://static.opengameart.org/OGA-BY-3.0.txt',
  'OFL-1.1': 'https://openfontlicense.org/open-font-license-official-text/',
  'CC-BY-SA-4.0': 'https://creativecommons.org/licenses/by-sa/4.0/'
};

/** CC-BY-SA is allowed only unmodified (a modified SA asset would put the share-alike condition on the game). */
export function licenseAllowed(license: string, modifications: string): boolean {
  if (!(LICENSES as readonly string[]).includes(license)) return false;
  if (license === 'CC-BY-SA-4.0') return modifications === 'none';
  return true;
}
```

```ts
  file: z.string().regex(/^(raw|art)\/[^\s]+$/, 'file must be a path under raw/ or art/ (relative to public/assets)'),
  title: z.string().min(1), author: z.string().min(1), source: z.string().min(1),
  archived: z.string().url().optional(),
  license: z.enum(LICENSES, { errorMap: () => ({ message: `license must be one of ${LICENSES.join(', ')}` }) }),
  licenseUrl: z.string().url().optional(),
  /** Path under public/assets of a licence text to append verbatim to the notices (required for OFL fonts). */
  licenseFile: z.string().optional(),
  retrieved: z.string().regex(/^\d{4}-\d{2}-\d{2}$/).optional(),
  modifications: z.string().min(1).default('none'),
  editedBy: z.string().min(1).optional(),
  credit: z.string().min(1).optional(),
  required: z.boolean().default(true),
  name: z.string().min(1).optional(),
  sheet: sheet.optional(),
  nineSlice: nineSlice.optional()
}).superRefine((e, ctx) => {
  const fail = (message: string): void => { ctx.addIssue({ code: z.ZodIssueCode.custom, message: `${e.file}: ${message}` }); };
  if ((e.name === undefined) === (e.sheet === undefined)) fail('exactly one of name or sheet is required');
  if (!licenseAllowed(e.license, e.modifications)) fail(`CC-BY-SA is allowed only with modifications "none" (license ${e.license})`);
  if (e.license.startsWith('CC-BY')) { if (!e.credit) fail('CC-BY entries need a credit line'); if (!e.archived) fail('CC-BY entries need an archived URL'); }
  if (e.license === 'OFL-1.1' && !e.licenseFile) fail('OFL entries need licenseFile (the OFL text to ship)');
  if (e.license === 'original') {
    if (e.author !== OWNER_AUTHOR) fail(`original pieces must name ${OWNER_AUTHOR} as author`);
    if (e.source !== 'assets/art') fail('original pieces must use source "assets/art"');
    if (e.archived) fail('original pieces have no archived URL');
    if (!e.file.startsWith('art/')) fail('original pieces live under art/');
  } else if (e.file.startsWith('art/')) {
    // A derived file: an edit of a third-party asset keeps that asset's provenance and records the edit.
    if (e.modifications === 'none') fail('derived art/ files must describe their modifications');
    if (!e.editedBy) fail('derived art/ files must name editedBy');
  }
});

const manifest = z.array(entry).superRefine((all, ctx) => {
  const seen = new Set<string>();
  for (const e of all) { if (seen.has(e.file)) ctx.addIssue({ code: z.ZodIssueCode.custom, message: `${e.file}: listed twice` }); seen.add(e.file); }
});

export type ManifestEntry = z.infer<typeof entry>;
export type Manifest = ManifestEntry[];

export function parseManifest(json: unknown): Manifest {
  const r = manifest.safeParse(json);
  if (!r.success) throw new Error('Invalid asset manifest: ' + r.error.issues.map((i) => i.message).join('; '));
  return r.data;
}

/** Names an entry binds: its single name, or its sheet's static frames then animations. */
export function boundNames(e: ManifestEntry): string[] {
  if (e.name !== undefined) return [e.name];
  return [...Object.keys(e.sheet!.frames), ...Object.keys(e.sheet!.animations)];
}
```

```ts
const SIGNATURE = [0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a];

/** Width and height from a PNG's IHDR chunk (bytes 16-23, big-endian). No dependency; enough for grid checks. */
export function pngSize(bytes: Uint8Array): { width: number; height: number } {
  if (bytes.length < 24 || SIGNATURE.some((v, i) => bytes[i] !== v)) throw new Error('not a PNG');
  if (String.fromCharCode(bytes[12]!, bytes[13]!, bytes[14]!, bytes[15]!) !== 'IHDR') throw new Error('PNG without IHDR first');
  const dv = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  return { width: dv.getUint32(16), height: dv.getUint32(20) };
}
```

```ts
import type { Manifest, ManifestEntry } from './manifest';
import { LICENSE_URLS, OWNER_AUTHOR } from './licenses';

/** One attribution block per distinct (title, author, source, license, modifications) across files. */
function groups(m: Manifest): { key: string; entries: ManifestEntry[] }[] {
  const by = new Map<string, ManifestEntry[]>();
  for (const e of m) { const k = [e.title, e.author, e.source, e.license, e.modifications].join('\u0000'); by.set(k, [...(by.get(k) ?? []), e]); }
  return [...by].map(([key, entries]) => ({ key, entries })).sort((a, b) => a.key.localeCompare(b.key));
}

export function buildNotices(m: Manifest, readLicenseFile: (path: string) => string): string {
  const out: string[] = ['FTLite third-party notices', 'Generated by scripts/gen-credits.ts from public/assets/manifest.json. Do not edit by hand.', ''];
  const third = m.filter((e) => e.license !== 'original');
  const licences = [...new Set(third.map((e) => e.license))].sort();
  for (const lic of licences) {
    out.push(`== ${lic} (${LICENSE_URLS[lic as keyof typeof LICENSE_URLS]}) ==`, '');
    for (const g of groups(third.filter((e) => e.license === lic))) {
      const e = g.entries[0]!;
      out.push(e.credit ?? `${e.title} by ${e.author}`);
      out.push(`  Title: ${e.title}`, `  Author: ${e.author}`, `  Source: ${e.source}`);
      if (e.archived) out.push(`  Archived: ${e.archived}`);
      out.push(`  Licence: ${lic} ${e.licenseUrl ?? LICENSE_URLS[lic as keyof typeof LICENSE_URLS]}`);
      out.push(`  Modifications: ${e.modifications}${e.editedBy ? ` (edited by ${e.editedBy})` : ''}`);
      if (e.retrieved) out.push(`  Retrieved: ${e.retrieved}`);
      out.push(`  Files: ${g.entries.map((x) => x.file).sort().join(', ')}`, '');
    }
  }
  const licenseFiles = [...new Set(third.map((e) => e.licenseFile).filter((p): p is string => !!p))].sort();
  for (const p of licenseFiles) out.push(`== Licence text: ${p} ==`, '', readLicenseFile(p).trimEnd(), '');
  return out.join('\n');
}

export function buildCreditLines(m: Manifest): string[] {
  const lines = ['FTLite', ''];
  const seen = new Set<string>();
  for (const g of groups(m.filter((e) => e.license !== 'original'))) {
    const e = g.entries[0]!;
    const line = e.credit ?? `${e.title} by ${e.author}, ${e.license}`;
    if (!seen.has(line)) { seen.add(line); lines.push(line); }
  }
  lines.push('', `Original art: ${OWNER_AUTHOR}`);
  return lines;
}
```

```ts
export interface Rect { x: number; y: number; w: number; h: number }

/** Row-major frame rectangles over a grid-sliced sheet. Throws if the grid does not divide the image (the assets test checks this too). */
export function sliceGrid(imageW: number, imageH: number, frameW: number, frameH: number): Rect[] {
  if (frameW <= 0 || frameH <= 0 || imageW % frameW !== 0 || imageH % frameH !== 0) throw new Error(`frame ${frameW}x${frameH} does not divide image ${imageW}x${imageH}`);
  const out: Rect[] = [];
  for (let y = 0; y < imageH; y += frameH) for (let x = 0; x < imageW; x += frameW) out.push({ x, y, w: frameW, h: frameH });
  return out;
}
```

```ts
/** Deterministic variant choice so the ship looks identical every run (spec §4). Knuth multiplicative hash, reduced from its high 16 bits (the low bits of i × odd are the low bits of i, so `% 4` on them would stripe); no RNG stream touched. */
export function pickVariant(seedIndex: number, count: number): number {
  if (count <= 1) return 0;
  return (((Math.imul(seedIndex | 0, 0x9e3779b1) >>> 0) >>> 16) % count);
}

export function floorVariant(roomIndex: number): number { return pickVariant(roomIndex, 4); }

const WALLS = ['wall.plain', 'wall.vent', 'wall.pipes', 'wall.screen'] as const;
export function wallVariant(tileIndex: number): (typeof WALLS)[number] { return WALLS[pickVariant(tileIndex, WALLS.length)]!; }

/** Spec §2: a wall gets the tall front-wall sprite only when the tile above is not a floor (void, wall, out of bounds). Door tiles ('+') count as floor. */
export function wallKind(rows: readonly string[], tx: number, ty: number): 'tall' | 'flat' {
  if (ty === 0) return 'tall';
  const above = rows[ty - 1]!.charAt(tx);
  return above === '#' || above === ' ' || above === '' ? 'tall' : 'flat';
}
```

```ts
import { DoorState } from '../sim/grid';

export const DOOR_ANIM_SECONDS = 0.25;

export function doorTarget(state: number): 0 | 1 { return state === DoorState.Open ? 1 : 0; }
export function initialDoorProgress(state: number): number { return doorTarget(state); }

/** Move progress towards target by dt / animSeconds, clamped to [0, 1]. Pure; called once per rendered frame per door. */
export function advanceDoor(progress: number, target: 0 | 1, dtSeconds: number, animSeconds: number): number {
  const stepSize = dtSeconds / animSeconds;
  if (target > progress) return Math.min(target, progress + stepSize);
  return Math.max(target, progress - stepSize);
}

/** Which texture a door shows: Sealed is the static sealed frame (sealing is instant); otherwise an open-animation frame by progress. */
export function doorFrame(state: number, progress: number, openFrames: number): { kind: 'sealed' } | { kind: 'open'; frame: number } {
  if (state === DoorState.Sealed) return { kind: 'sealed' };
  return { kind: 'open', frame: Math.round(progress * Math.max(0, openFrames - 1)) };
}
```

```ts
/** A required file could not be loaded: startup stops (spec §7). `files` lists every failed required file. */
export class AssetError extends Error {
  constructor(message: string, public readonly files: string[]) { super(message); this.name = 'AssetError'; }

export const FONT_FAMILY = 'm5x7';
const FONT_SIZE = 16;
const ASCII = Array.from({ length: 95 }, (_, i) => String.fromCharCode(32 + i)).join('');

async function loadImage(url: string): Promise<Texture> {
  const tex = await Assets.load<Texture>({ src: url, parser: 'loadTextures' });
  tex.source.scaleMode = 'nearest';

async function loadFont(url: string): Promise<void> {

  BitmapFont.install({ name: FONT_FAMILY, style: { fontFamily: FONT_FAMILY, fontSize: FONT_SIZE, fill: 0xffffff }, chars: ASCII, resolution: 1, textureStyle: { scaleMode: 'nearest' } });

/** fetch() first; XMLHttpRequest if the packaged app's file:// origin refuses fetch (Chromium does, some Electron versions allow it). */
async function loadJson(url: string): Promise<unknown> {
  try { const res = await fetch(url); if (!res.ok) throw new Error(`HTTP ${res.status}`); return await res.json(); }
  catch (fetchErr) {
    return new Promise((resolve, reject) => {
      const xhr = new XMLHttpRequest(); xhr.open('GET', url); xhr.responseType = 'text';
      xhr.onload = () => { try { resolve(JSON.parse(xhr.responseText)); } catch (e) { reject(e); } };
      xhr.onerror = () => reject(new AssetError(`Cannot load ${url}: ${String(fetchErr)}`, [url]));
      xhr.send();
    });
  }
}

export async function loadAssets(manifestUrl: string): Promise<GameAssets> {
  // The packaged app runs from file://, where Chromium refuses fetch(); Pixi's default ImageBitmap path uses fetch, so take the <img> path everywhere.
  if (loadTextures.config) loadTextures.config.preferCreateImageBitmap = false;
  const manifestAbs = new URL(manifestUrl, document.baseURI);
  const manifest = parseManifest(await loadJson(manifestAbs.href));   // throws "Invalid asset manifest: ..." (spec §7)
  const base = new URL('.', manifestAbs);                              // the directory holding manifest.json: .../assets/
  const textures = new Map<string, Texture>();
  const animations = new Map<string, GameAnimation>();
  const nines = new Map<string, GameNineSlice>();
  const failedRequired: string[] = [];

  for (const e of manifest) {
    const url = new URL(e.file, base).href;
    try {
      if (e.name?.startsWith('font.')) { await loadFont(url); continue; }
      const tex = await loadImage(url);
      bind(e, tex, textures, animations, nines);
    } catch (err) {
      if (e.required) { failedRequired.push(e.file); console.error(`required asset failed: ${e.file}`, err); }
      else console.warn(`optional asset missing, placeholder in use: ${e.file}`);
    }
  }
  if (failedRequired.length) throw new AssetError(`Required assets failed to load:\n${failedRequired.join('\n')}`, failedRequired);

  const has = (n: string): boolean => textures.has(n) || animations.has(n) || (n === 'font.m5x7');
  // Every optional name that did not end up loaded, whether its file failed or it was never bound in the manifest.
  const missing = Object.keys(ASSET_NAMES).filter((n) => ASSET_NAMES[n] === 'optional' && !has(n));
  return {
    has, missing, fontFamily: FONT_FAMILY,
    texture(n) { const t = textures.get(n); if (!t) throw new Error(`no texture bound to ${n}`); return t; },
    animation(n) { const a = animations.get(n); if (!a) throw new Error(`no animation bound to ${n}`); return a; },
    nineSlice(n) { const s = nines.get(n); if (!s) throw new Error(`no nineSlice for ${n}`); return s; }
  };
}

function bind(e: ManifestEntry, tex: Texture, textures: Map<string, Texture>, animations: Map<string, GameAnimation>, nines: Map<string, GameNineSlice>): void {
  if (e.name !== undefined) {
    textures.set(e.name, tex);
    if (e.nineSlice) nines.set(e.name, { texture: tex, ...e.nineSlice });
    return;
  }
  const s = e.sheet!;
  const frames = sliceGrid(tex.width, tex.height, s.frameW, s.frameH).map((r) => new Texture({ source: tex.source, frame: new Rectangle(r.x, r.y, r.w, r.h) }));
  const at = (i: number): Texture => { const t = frames[i]; if (!t) throw new Error(`${e.file}: frame ${i} out of range (${frames.length})`); return t; };
  for (const [n, i] of Object.entries(s.frames)) textures.set(n, at(i));
  for (const [n, a] of Object.entries(s.animations)) animations.set(n, { textures: a.frames.map(at), fps: a.fps, loop: a.loop });
}
```

```ts
import { Container, Sprite, type Texture } from 'pixi.js';
import { TILE_PX } from '../../../shared/resolution';
import type { SimState } from '../sim/state';
import type { GameAssets } from './assets';
import type { RenderMemory } from './memory';
import { floorVariant, wallVariant, wallKind } from './tilePick';
import { advanceDoor, doorTarget, doorFrame, initialDoorProgress, DOOR_ANIM_SECONDS } from './doorAnim';

export interface TileLayer { container: Container; build(state: SimState): void; update(state: SimState, dtSeconds: number): void }

const SCALE = TILE_PX / 16;   // 16 px art drawn at 2x

function tileSprite(tex: Texture, tx: number, ty: number): Sprite {
  const s = new Sprite(tex); s.scale.set(SCALE); s.position.set(tx * TILE_PX, ty * TILE_PX); return s;
}
/** Tall art (16×32 walls or doors) sits on the bottom-left of its tile and extends one tile upward (spec §2). */
function bottomAnchored(tex: Texture, tx: number, ty: number): Sprite {
  const s = new Sprite(tex); s.scale.set(SCALE); s.anchor.set(0, 1); s.position.set(tx * TILE_PX, (ty + 1) * TILE_PX); return s;
}

/** Floors, walls and doors as plain sprites. Built once per layout (never rebuilt in Increment 1); doors are reconciled every frame. */
export function createTileLayer(assets: GameAssets, memory: RenderMemory): TileLayer {
  const container = new Container();
  const floors = new Container(), walls = new Container(), doors = new Container();
  container.addChild(floors, walls, doors);
  const doorSprites: Sprite[] = [];        // per edge index; non-door edges have no sprite
  const openFrames = assets.animation('door.open').textures;
  const sealed = assets.texture('door.sealed');
  let builtFor: string | null = null;

  function build(state: SimState): void {
      const d = state.derived, rows = state.layout.rows;
      floors.removeChildren(); walls.removeChildren(); doors.removeChildren(); doorSprites.length = 0;
      for (let ty = 0; ty < d.height; ty++) for (let tx = 0; tx < d.width; tx++) {
        const i = ty * d.width + tx, c = rows[ty]!.charAt(tx);
        if (c === ' ') continue;                                                  // void: nothing drawn
        if (c === '#') {
          if (wallKind(rows, tx, ty) === 'tall') walls.addChild(bottomAnchored(assets.texture(wallVariant(i)), tx, ty));
          else walls.addChild(tileSprite(assets.texture('wall.flat'), tx, ty));
          continue;
        }
        const room = d.roomOfTile[i]!;
        const variant = room >= 0 ? floorVariant(room) : floorVariant(i);          // door tiles get a floor underneath
        floors.addChild(tileSprite(assets.texture(`floor.${variant}`), tx, ty));
      }
      for (let e = 0; e < d.edgeIsDoor.length; e++) {
        if (!d.edgeIsDoor[e]) continue;
        const t = d.edgeTile[e]!, tx = t % d.width, ty = (t - tx) / d.width;
        const s = bottomAnchored(openFrames[0]!, tx, ty); doors.addChild(s); doorSprites[e] = s;
      }
      builtFor = d.layoutHash;
  }

  return {
    container, build,
    update(state, dt) {
      if (builtFor !== state.derived.layoutHash) build(state);
      const E = state.doors.state.length;
      if (!memory.doorProgress) memory.doorProgress = Array.from(state.doors.state, (st) => initialDoorProgress(st));
      for (let e = 0; e < E; e++) {
        const s = doorSprites[e]; if (!s) continue;
        const st = state.doors.state[e]!;
        memory.doorProgress[e] = advanceDoor(memory.doorProgress[e]!, doorTarget(st), dt, DOOR_ANIM_SECONDS);
        const f = doorFrame(st, memory.doorProgress[e]!, openFrames.length);
        s.texture = f.kind === 'sealed' ? sealed : openFrames[f.frame]!;
      }
    }
  };
}
```

```ts
      }
    }
  };
}
```

```ts
import type { Facing8 } from './assetNames';

export const MOVE_EPS_PX = 1e-4;
const TAN_22_5 = 0.41421356;   // tan(22.5°): the cardinal sectors are ±22.5° wide

/** 8-way facing from a movement delta (y down). Idle keeps the previous facing (last non-zero delta). No trig: sector by slope. */
export function facingFromDelta(dx: number, dy: number, previous: Facing8): Facing8 {
  const ax = Math.abs(dx), ay = Math.abs(dy);
  if (ax < MOVE_EPS_PX && ay < MOVE_EPS_PX) return previous;
  if (ay <= ax * TAN_22_5) return dx > 0 ? 'e' : 'w';
  if (ax <= ay * TAN_22_5) return dy > 0 ? 's' : 'n';
  if (dy < 0) return dx > 0 ? 'ne' : 'nw';
  return dx > 0 ? 'se' : 'sw';
}
```

```ts
import type { Derived } from '../sim/ship/derived';

/** Stable order of a room's tiles: a bijective hash of the tile index, so the burning subset grows as a prefix (spec §4). */
function stableOrder(tiles: readonly number[]): number[] {
  return [...tiles].sort((a, b) => ((Math.imul(a, 0x9e3779b1) >>> 0) - (Math.imul(b, 0x9e3779b1) >>> 0)) || a - b);
}

export function fireTiles(roomTiles: readonly number[], fire: number, fireCap: number): number[] {
  if (fire <= 0 || roomTiles.length === 0) return [];
  const count = Math.min(roomTiles.length, Math.ceil((fire / fireCap) * roomTiles.length));
  return stableOrder(roomTiles).slice(0, Math.max(1, count));
}

const AROUND = [[0, -1], [-1, 0], [1, 0], [0, 1]] as const;   // up, left, right, down (tile-index order)

/** The 4-neighbour floor tiles of a breach site that belong to the breached room (the site itself is a wall tile). */
export function breachDamagedTiles(d: Derived, site: number): number[] {
  const t = d.siteTile[site]!, tx = t % d.width, ty = (t - tx) / d.width, out: number[] = [];
  for (const [ox, oy] of AROUND) {
    const nx = tx + ox, ny = ty + oy;
    if (nx < 0 || ny < 0 || nx >= d.width) continue;
    const n = ny * d.width + nx;
    if (n >= d.roomOfTile.length) continue;
    if (d.roomOfTile[n] === d.siteRoom[site]) out.push(n);
  }
  return out;
}

export function breachFloorNeighbour(d: Derived, site: number): number { return breachDamagedTiles(d, site)[0] ?? -1; }

/** Horizontal wall (floor above or below the site) → 'h'; side wall → 'v'. */
export function breachOrientation(d: Derived, site: number): 'h' | 'v' {
  const f = breachFloorNeighbour(d, site);
  if (f < 0) return 'h';
  return (f % d.width) === (d.siteTile[site]! % d.width) ? 'h' : 'v';
}

/** Rotation for the vent puff, drawn travelling upward (−y) at rotation 0; direction = site − floor neighbour. */
export function ventRotation(d: Derived, site: number): number {
  const f = breachFloorNeighbour(d, site);
  if (f < 0) return 0;
  const s = d.siteTile[site]!;
  const dx = (s % d.width) - (f % d.width), dy = Math.trunc(s / d.width) - Math.trunc(f / d.width);
  if (dy < 0) return 0; if (dx > 0) return Math.PI / 2; if (dy > 0) return Math.PI; return -Math.PI / 2;
}
```

```ts
const SCALE = TILE_PX / 16;
const ANCHOR_X = 0.5, ANCHOR_Y = 0.75;   // spec §2: feet at the bottom of the 0.6-tile collision box

export interface CrewLayer { container: Container; draw(state: SimState, alpha: number): void }

interface CrewSprite { sprite: AnimatedSprite; anim: string | null }

/** One AnimatedSprite per crew member, keyed by StableId. Falls back to the Increment 1 circles when any crew name is missing. */
export function createCrewLayer(assets: GameAssets, memory: RenderMemory): CrewLayer {
  const container = new Container();
  const useArt = featureReady(new Set(assets.missing), 'crew');
  const sprites = new Map<number, CrewSprite>();
  const circles = new Map<number, Graphics>();

  /** Interpolated draw position, and the movement since the last drawn frame (not since the last tick: a paused sim must read as idle). */
  const interpolated = (eid: number, alpha: number): { x: number; y: number; dx: number; dy: number } => {
    const id = Stable.id[eid]!, p = memory.prev.get(id) ?? { x: Position.x[eid]!, y: Position.y[eid]! };
    const x = p.x + (Position.x[eid]! - p.x) * alpha, y = p.y + (Position.y[eid]! - p.y) * alpha;
    const last = memory.lastDrawn.get(id) ?? { x, y };
    memory.lastDrawn.set(id, { x, y });
    return { x, y, dx: x - last.x, dy: y - last.y };
  };

  const setAnim = (cs: CrewSprite, name: string, textures: Texture[], fps: number, loop: boolean, startFrame = 0): void => {
    if (cs.anim === name) return;
    cs.anim = name;
    cs.sprite.textures = textures; cs.sprite.animationSpeed = fps / 60; cs.sprite.loop = loop;
    if (textures.length > 1) cs.sprite.gotoAndPlay(startFrame % textures.length); else cs.sprite.gotoAndStop(0);
  };

  return {
    container,
    draw(state, alpha) {
      const liveIds = state.crew.map((eid) => Stable.id[eid]!);
      if (!useArt) {
        syncCache(circles, liveIds, () => { const g = new Graphics(); container.addChild(g); return g; }, (g, id) => { g.destroy(); memory.prev.delete(id); memory.lastDrawn.delete(id); });
        for (const eid of state.crew) {
          const g = circles.get(Stable.id[eid]!)!, { x, y } = interpolated(eid, alpha), life = Life.state[eid];
          g.clear().circle(0, 0, CREW_HALF * TILE_PX).fill({ color: life === LifeState.Dead ? DEAD_TINT : CREW_COLORS[Owner.pid[eid]! % 4]!, alpha: life === LifeState.Downed ? 0.5 : 1 });
          g.position.set(x * TILE_PX, y * TILE_PX);
        }
        return;
      }
      syncCache(sprites, liveIds,
        () => { const s = new AnimatedSprite([assets.texture('crew.idle.s')]); s.anchor.set(ANCHOR_X, ANCHOR_Y); s.scale.set(SCALE); container.addChild(s); return { sprite: s, anim: null }; },
        (cs, id) => { cs.sprite.destroy(); memory.prev.delete(id); memory.lastDrawn.delete(id); memory.facing.delete(id); });
      for (const eid of state.crew) {
        const id = Stable.id[eid]!, cs = sprites.get(id)!, { x, y, dx, dy } = interpolated(eid, alpha);
        const facing: Facing8 = facingFromDelta(dx, dy, memory.facing.get(id) ?? 's');
        memory.facing.set(id, facing);
        const life = Life.state[eid];
        const moving = Math.abs(dx) >= MOVE_EPS_PX || Math.abs(dy) >= MOVE_EPS_PX;
        if (life !== LifeState.Conscious) setAnim(cs, 'crew.down', [assets.texture('crew.down')], 1, false);
        else if (!moving) setAnim(cs, `crew.idle.${facing}`, [assets.texture(`crew.idle.${facing}`)], 1, false);
        else { const a = assets.animation(`crew.walk.${facing}`); setAnim(cs, `crew.walk.${facing}`, a.textures, a.fps, a.loop, id); }
        cs.sprite.tint = life === LifeState.Dead ? DEAD_TINT : CREW_COLORS[Owner.pid[eid]! % 4]!;
        cs.sprite.alpha = life === LifeState.Downed ? 0.85 : 1;
        cs.sprite.position.set(x * TILE_PX, y * TILE_PX);
      }
    }
  };
}
```

```ts
import type { SimState } from '../sim/state';
import { Health, Life, LifeState, Position } from '../sim/components';
import { interactTarget, confirmTarget, TargetKind, ConfirmKind } from '../sim/interact';
import { DoorState, conditionRoomAt } from '../sim/grid';
import { TICK_HZ } from '../sim/tuning';
import type { SlotInfo, SlotStatus } from '../input/deviceManager';

export type DeviceKind = 'kb0' | 'kb1' | 'pad' | null;
export type HudAction = 'interact' | 'confirm' | 'cancel';
export interface HudPlayer {
  pid: number; status: SlotStatus; deviceKind: DeviceKind;
  health: number; life: number; bleed: number; lowOxygen: boolean;
  lifeText: string;
  interactPrompt: string; interactIcon: string | null;
  confirmPrompt: string; confirmIcon: string | null;
  progress: number;
}
export interface HudThreat { icon: 'icon.fire' | 'icon.breach'; text: string }
export interface HudModel {
  phase: 'lobby' | 'running' | 'paused' | 'gameover' | 'error'; message: string; hull: number; simSeconds: number;
  threats: HudThreat[]; players: HudPlayer[]; credits: string[] | null; creditsScroll: number;
}

/** A player's room is "low" on the HUD below this oxygen fraction (a warning, well above SUFFOCATE_FRAC). */
export const HUD_LOW_O2_FRAC = 0.5;

/** Slot key → device kind. The key format is owned by input/sources.ts (`kb:0`, `kb:1`, `gp:<index>`); nothing else is parsed from it. */
export function deviceKindOf(key: string | null): DeviceKind {
  if (key === 'kb:0') return 'kb0'; if (key === 'kb:1') return 'kb1'; if (key?.startsWith('gp:')) return 'pad'; return null;
}

const GLYPHS: Record<Exclude<DeviceKind, null>, Record<HudAction, string>> = {
  kb0: { interact: 'prompt.kb.E', confirm: 'prompt.kb.F', cancel: 'prompt.kb.Q' },
  kb1: { interact: 'prompt.kb.Enter', confirm: 'prompt.kb.ShiftRight', cancel: 'prompt.kb.Backspace' },
  pad: { interact: 'prompt.pad.A', confirm: 'prompt.pad.X', cancel: 'prompt.pad.B' }
};
export function glyphName(action: HudAction, kind: DeviceKind): string | null { return kind ? GLYPHS[kind][action] : null; }

const EMPTY = { health: 0, life: 0, bleed: 0, lowOxygen: false, lifeText: '', interactPrompt: '', interactIcon: null, confirmPrompt: '', confirmIcon: null, progress: 0 } as const;

function player(state: SimState, pid: number): Omit<HudPlayer, 'pid' | 'status' | 'deviceKind'> {
  const eid = state.crew[pid]!;
  const base = { health: Health.cur[eid]!, life: Life.state[eid]!, bleed: Life.bleed[eid]! };
  const r = conditionRoomAt(state, Position.x[eid]!, Position.y[eid]!);
  const lowOxygen = r >= 0 && state.rooms.o2[r]! / state.derived.volume[r]! < HUD_LOW_O2_FRAC;
  if (Life.state[eid] === LifeState.Downed) return { ...EMPTY, ...base, lowOxygen, lifeText: `DOWNED ${Math.ceil(Life.bleed[eid]!)}s`, progress: Life.reviveProgress[eid]! };
  if (Life.state[eid] === LifeState.Dead) return { ...EMPTY, ...base, lowOxygen, lifeText: 'DEAD' };
  let interactPrompt = '', interactIcon: string | null = null, progress = 0;
  const t = interactTarget(state, pid);
  if (t.kind === TargetKind.Revive) { interactPrompt = `Revive P${t.index + 1}`; progress = Life.reviveProgress[state.crew[t.index]!]!; }
  else if (t.kind === TargetKind.Fire) { interactPrompt = 'Repair fire'; interactIcon = 'icon.repair'; progress = state.rooms.fireRepair[t.index]!; }
  else if (t.kind === TargetKind.Breach) { interactPrompt = 'Repair breach'; interactIcon = 'icon.repair'; progress = state.breaches.repair[t.index]!; }
  let confirmPrompt = '', confirmIcon: string | null = null;
  const c = confirmTarget(state, pid);
  if (c.kind === ConfirmKind.Door) { confirmPrompt = state.doors.state[c.index] === DoorState.Sealed ? 'Unseal door' : 'Seal door'; confirmIcon = 'icon.door'; }
  return { ...base, lowOxygen, lifeText: '', interactPrompt, interactIcon, confirmPrompt, confirmIcon, progress };
}

export function buildHudModel(state: SimState | null, slots: SlotInfo[], phase: HudModel['phase'], message: string, credits: { lines: readonly string[]; scroll: number } | null = null): HudModel {
  const players: HudPlayer[] = slots.map((slot, pid) => {
    const head = { pid, status: slot.status, deviceKind: slot.status === 'active' ? deviceKindOf(slot.key) : null };
    if (!state || pid >= state.playerCount) return { ...head, ...EMPTY };
    return { ...head, ...player(state, pid) };
  });
  const threats: HudThreat[] = [];
  if (state) {
    for (let r = 0; r < state.rooms.fire.length; r++) if (state.rooms.fire[r]! > 0) threats.push({ icon: 'icon.fire', text: `Fire: ${state.layout.rooms[r]!.name}` });
    for (let s = 0; s < state.breaches.active.length; s++) if (state.breaches.active[s]) threats.push({ icon: 'icon.breach', text: `Breach: ${state.layout.rooms[state.derived.siteRoom[s]!]!.name}` });
  }
  return { phase, message, hull: state?.hull ?? 0, simSeconds: state ? Math.floor(state.tick / TICK_HZ) : 0, threats, players, credits: credits ? [...credits.lines] : null, creditsScroll: credits?.scroll ?? 0 };
}
```

```ts
import { Container, Sprite, BitmapText, NineSliceSprite, type Texture } from 'pixi.js';
import { INTERNAL_W, INTERNAL_H } from '../../../shared/resolution';
import type { GameAssets } from './assets';
import { glyphName, type HudModel, type HudPlayer } from './hudModel';
import { featureReady } from './fallback';

const TEXT = 0xe8e8e8, DIM = 0x9aa0ad, WARN = 0xff6b5a;
const LINE = 18;                 // px per text line at 16 px m5x7
const CREDITS_LINES = 22;

/** HUD art is drawn at 1x (16 px font, 16 px glyphs and icons); the stage's integer letterbox scale does the rest. */
export function createHud(parent: Container, assets: GameAssets) {
  const missing = new Set(assets.missing);
  const glyphs = featureReady(missing, 'glyphs'), icons = featureReady(missing, 'icons');
  const text = (size = 16, tint = TEXT): BitmapText => { const t = new BitmapText({ text: '', style: { fontFamily: assets.fontFamily, fontSize: size } }); t.tint = tint; t.roundPixels = true; return t; };
  const panel = (x: number, y: number, w: number, h: number): NineSliceSprite => {
    const n = assets.nineSlice('ui.panel');
    const p = new NineSliceSprite({ texture: n.texture, leftWidth: n.left, topHeight: n.top, rightWidth: n.right, bottomHeight: n.bottom });
    p.width = w; p.height = h; p.position.set(x, y); return p;
  };
  const icon = (name: string | null): Sprite | null => (name && icons && assets.has(name)) ? new Sprite(assets.texture(name)) : null;
  const bar = (w: number): { root: Container; set(frac: number): void } => {
    const root = new Container(); const bg = new Sprite(assets.texture('ui.bar.bg')); bg.width = w; const fill = new Sprite(assets.texture('ui.bar.fill'));
    root.addChild(bg, fill);
    return { root, set(frac) { fill.width = Math.max(0, Math.min(1, frac)) * w; fill.visible = frac > 0; } };
  };

  // Top-left: hull and clock. Top-right: threats. Centre: banner. Bottom: four player blocks. Overlay: credits.
  parent.addChild(panel(4, 4, 200, 40));
  const top = text(); top.position.set(12, 14); parent.addChild(top);
  parent.addChild(panel(INTERNAL_W - 232, 4, 228, 100));
  const threatRows = Array.from({ length: 4 }, (_, i) => { const row = new Container(); row.position.set(INTERNAL_W - 224, 12 + i * LINE); parent.addChild(row); return row; });
  const banner = text(16); banner.scale.set(2); banner.anchor.set(0.5, 0); banner.position.set(INTERNAL_W / 2, 24); parent.addChild(banner);
  const bannerGlyphs = new Container(); bannerGlyphs.position.set(INTERNAL_W / 2, 64); parent.addChild(bannerGlyphs);

  const players = [0, 1, 2, 3].map((i) => {
    const x = 4 + i * 238, y = INTERNAL_H - 76;
    parent.addChild(panel(x, y, 234, 72));
    const root = new Container(); root.position.set(x + 8, y + 8); parent.addChild(root);
    const name = text(); const hp = bar(96); hp.root.position.set(110, 2);
    const oxygen = icon('icon.oxygen'); if (oxygen) { oxygen.position.set(210, 0); oxygen.visible = false; root.addChild(oxygen); }
    const line2 = new Container(); line2.position.set(0, LINE);
    const line3 = new Container(); line3.position.set(0, LINE * 2);
    const progress = bar(216); progress.root.position.set(0, LINE * 3 - 6); progress.root.visible = false;
    root.addChild(name, hp.root, line2, line3, progress.root);
    return { name, hp, oxygen, line2, line3, progress };
  });

  const overlay = new Container(); overlay.visible = false;
  overlay.addChild(panel(40, 40, INTERNAL_W - 80, INTERNAL_H - 80));
  const creditLines = Array.from({ length: CREDITS_LINES }, (_, i) => { const t = text(); t.position.set(56, 56 + i * LINE); overlay.addChild(t); return t; });
  const creditsFooter = text(16, DIM); creditsFooter.position.set(56, INTERNAL_H - 64); creditsFooter.text = 'Up/Down: scroll    Confirm or Cancel: close'; overlay.addChild(creditsFooter);
  parent.addChild(overlay);

  /** Rebuild a row as [glyph] [icon] text, left to right. Rows are rebuilt only when their text key changes. */
  const rowKeys = new WeakMap<Container, string>();
  function fillRow(row: Container, parts: { glyph?: string | null; icon?: string | null; text: string; tint?: number }[]): void {
    const key = JSON.stringify(parts);
    if (rowKeys.get(row) === key) return;
    rowKeys.set(row, key);
    for (const c of row.removeChildren()) c.destroy();   // destroys the text/sprite objects, not the shared textures
    let x = 0;
    for (const p of parts) {
      if (!p.text && !p.glyph) continue;
      if (p.glyph && glyphs && assets.has(p.glyph)) { const g = new Sprite(assets.texture(p.glyph)); g.position.set(x, 0); row.addChild(g); x += 20; }
      const ic = icon(p.icon ?? null); if (ic) { ic.position.set(x, 0); row.addChild(ic); x += 20; }
      const t = text(16, p.tint ?? TEXT); t.text = p.text; t.position.set(x, 1); row.addChild(t); x += Math.ceil(t.width) + 12;
    }
  }

  function updatePlayer(ui: (typeof players)[number], p: HudPlayer, i: number): void {
    if (p.status === 'empty') { ui.name.text = `P${i + 1}: press Interact to join`; ui.name.tint = DIM; ui.hp.root.visible = false; fillRow(ui.line2, []); fillRow(ui.line3, []); ui.progress.root.visible = false; if (ui.oxygen) ui.oxygen.visible = false; return; }
    if (p.status === 'reconnect') { ui.name.text = `P${i + 1}: RECONNECT`; ui.name.tint = WARN; ui.hp.root.visible = false; fillRow(ui.line2, []); fillRow(ui.line3, []); ui.progress.root.visible = false; if (ui.oxygen) ui.oxygen.visible = false; return; }
    ui.name.text = `P${i + 1}  HP ${Math.ceil(p.health)}`; ui.name.tint = TEXT;
    ui.hp.root.visible = true; ui.hp.set(p.health / 100);
    if (ui.oxygen) ui.oxygen.visible = p.lowOxygen;
    if (p.lifeText) { fillRow(ui.line2, [{ text: p.lifeText, tint: WARN }]); fillRow(ui.line3, []); }
    else {
      fillRow(ui.line2, [{ glyph: p.interactPrompt ? glyphName('interact', p.deviceKind) : null, icon: p.interactIcon, text: p.interactPrompt }]);
      fillRow(ui.line3, [{ glyph: p.confirmPrompt ? glyphName('confirm', p.deviceKind) : null, icon: p.confirmIcon, text: p.confirmPrompt }]);
    }
    ui.progress.root.visible = p.progress > 0; ui.progress.set(p.progress);
  }

  return {
    update(m: HudModel): void {
      top.text = `HULL ${Math.round(m.hull)}   TIME ${m.simSeconds}s`;
      threatRows.forEach((row, i) => { const t = m.threats[i]; fillRow(row, t ? [{ icon: t.icon, text: t.text, tint: WARN }] : []); });
      banner.text = m.message;
      // Cancel (and Confirm) glyphs appear only with the lobby and game-over banners, for the first joined player's device.
      const first = m.players.find((p) => p.status === 'active');
      const showBannerGlyphs = (m.phase === 'lobby' || m.phase === 'gameover') && !!first?.deviceKind;
      fillRow(bannerGlyphs, showBannerGlyphs ? [{ glyph: glyphName('confirm', first!.deviceKind), text: 'Confirm' }, { glyph: glyphName('cancel', first!.deviceKind), text: 'Cancel' }] : []);
      bannerGlyphs.position.x = INTERNAL_W / 2 - bannerGlyphs.width / 2;
      m.players.forEach((p, i) => updatePlayer(players[i]!, p, i));
      overlay.visible = m.credits !== null;
      if (m.credits) creditLines.forEach((t, i) => { t.text = m.credits![m.creditsScroll + i] ?? ''; });
    }
  };
}
```

```ts
  /** One line per CREDITS_SCROLL_MS while any active stick is held up or down; the first step in a new direction is immediate. */
  function scrollCredits(frames: readonly InputFrame[], deltaMs: number): void {
    let dir = 0;
    for (const f of frames) if (f.moveY > 0.5) { dir = 1; break; } else if (f.moveY < -0.5) { dir = -1; break; }
    const max = Math.max(0, credits.length - 1);
    const stepOnce = (): void => { creditsScroll = Math.max(0, Math.min(max, creditsScroll + dir)); };
    if (dir !== scrollDir) { scrollDir = dir; scrollHold = 0; if (dir !== 0) stepOnce(); return; }   // new direction: step now, hold from zero
    if (dir === 0) return;
    scrollHold += deltaMs;
    while (scrollHold >= CREDITS_SCROLL_MS) { scrollHold -= CREDITS_SCROLL_MS; stepOnce(); }
  }
```
